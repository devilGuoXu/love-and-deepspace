Past Banner Value Review

Hindsight is 20/20. With a year of banner data, we can now rank every limited banner by actual account value — not hype. Here is which banners were worth the pulls and which ones you should have skipped.

ENTRY_#EVT_142026.07.03BANNER

Key Insight: Looking back at 12 months of limited banners, a clear pattern emerges: banners that introduced a new element or a new role type consistently outperformed rerun banners and side-grade character banners. The top 3 banners by account impact were all first-introduction banners. Rerun banners averaged 40% lower value than debut banners. Pulling on FOMO is the single biggest source of regret in retrospective surveys.

Over the first year, 16 limited banners were released across the four operatives. Of these, 10 were debut banners featuring a new memory for an operative, and 6 were reruns. The average banner value score across all banners was 3.2/5.0, meaning more than half of all banners were average or below. This reinforces the "skip 50%" rule — most banners are not worth your pulls.

Past Banner Tier List

Each banner is rated on a 5-point scale based on: (1) How much the rate-up memory improved the operative's performance, (2) How long the memory remained meta-relevant, (3) The operative's overall tier at the time of release, and (4) Retrospective regret rate (how many players wished they had pulled or skipped).

S-Tier — Must Pull Banners

These banners delivered exceptional account value. Players who pulled on these banners saw the highest return on investment in terms of content cleared and abyss scores.

S-TIER ★★★★★
Xavier — Light Seeker (Debut)
Released at launch, Xavier's Light Seeker memory defined the Light DPS role for the entire year. It remained the top single-target DPS memory for 8 months and was only slightly outclassed by the 1.5 update. Value score: 4.8/5.0. Regret rate: 2% (almost no one regretted pulling). This banner set the standard for future value evaluations — it was the benchmark every subsequent debut was measured against.
S-TIER ★★★★★
Sylus — Execute Protocol (Debut)
Released in version 1.1 after Sylus's execute rework. This memory capitalized on the newly buffed execute mechanic and turned Sylus from the weakest operative into the strongest single-target burst DPS. It remained top-tier through the anniversary update. Value score: 4.7/5.0. Regret rate: 5%. The only reason it is not 5.0 is that Sylus required specific team support to reach full potential.
S-TIER ★★★★★
Rafayel — Inferno Waltz (Debut)
Released in 1.2 alongside Rafayel's burn rework. This memory turned Rafayel into the undisputed king of AoE content. It made Abyss floors 7-9 significantly easier and was essential for the co-op boss meta. Value score: 4.6/5.0. Regret rate: 4%. Top-tier AoE memories are rare — this one carried accounts through three full patches of content.

A-Tier — Good Value Banners

A-TIER ★★★★☆
Zayne — Frostguard Oath (Debut)
Zayne's first limited memory was a strong support addition. It provided shields and team-wide ER buffs that elevated any team composition. Not flashy like the S-tier picks, but a consistent contributor to account performance. Value score: 4.1/5.0. Best for players who mained Zayne or ran double-DPS compositions.
A-TIER ★★★★☆
Xavier — Radiant Edge (1.2 Debut)
Xavier's second debut was a sidegrade to Light Seeker — slightly better in extended fights, slightly worse in burst windows. Not essential if you already had Light Seeker, but valuable for Xavier mains. Value score: 4.0/5.0. A textbook example of a "good but not must-pull" banner.
A-TIER ★★★★☆
Sylus — Dark Harvest (1.5 Debut)
Sylus's second memory focused on AoE execute rather than single-target. It filled a gap in his kit and made him viable in wave-based content. Value score: 3.9/5.0. Good for Sylus mains but not essential for account-wide value.

B-Tier — Situational Banners

B-TIER ★★★☆☆
Rafayel — Cinderspark (1.5 Debut)
A sidegrade to Inferno Waltz with a different playstyle (DoT stacking vs burst AoE). Interesting for variety but did not significantly improve Rafayel's performance. Value score: 3.2/5.0. Only pull if you mained Rafayel and wanted gameplay variety.
B-TIER ★★★☆☆
Xavier — Light Seeker Rerun
The rerun of the best banner in the game. Still good value for players who missed it the first time, but limited value for existing owners. Value score: 3.0/5.0. Regret rate: 15% — players who already had it felt pressured to pull for dupes, which most regretted.
B-TIER ★★★☆☆
Zayne — Frostguard Oath Rerun
Same story as the Xavier rerun — good for new players who missed it, low value for existing owners. Value score: 2.9/5.0. Only pull if you needed Zayne for your support slot.

F-Tier — Skip Banners

F-TIER ★★☆☆☆
Zayne — Hoarfrost Veil (1.4 Debut)
Widely considered the weakest debut of Year 1. The memory's kit was clunky, requiring specific enemy positioning that rarely aligned with actual content. Zayne's role as a pure support meant the memory's offensive orientation was wasted. Value score: 2.1/5.0. Regret rate: 68% — the highest regret rate of any banner. Players who pulled universally wished they had saved for the next banner instead.
F-TIER ★★☆☆☆
Sylus — Execute Protocol Rerun
Rerun banners generally underperform, but Sylus's rerun was particularly bad timing — it ran concurrently with a higher-value new banner, splitting player resources. Value score: 2.0/5.0. The opportunity cost of pulling this rerun instead of the concurrent debut was too high.
F-TIER ★★☆☆☆
Rafayel — Inferno Waltz Rerun
By the time this rerun arrived, Rafayel had already been power-crept by newer AoE options. The memory was still functional but no longer top-tier. Value score: 1.8/5.0. The lowest rated rerun. Players who pulled this over saving for the upcoming 2.0 anniversary banner expressed the highest overall regret in community surveys.

Rerun Reality: Across all 6 rerun banners, the average value score was 2.4/5.0 — a full 1.4 points lower than debut banners (3.8/5.0). This data strongly supports the advice to skip reruns unless you are a new player who missed the original run. The opportunity cost of pulling on a rerun instead of saving for an unknown future debut is almost never worth it. In every case where a rerun and a debut ran concurrently, the debut was the better pull.

Lessons for Future Banners

The retrospective data reveals clear patterns that can guide future banner decisions. First, debut banners consistently outperform reruns — skip reruns unless you are a new player. Second, first-introduction banners for a new role or element type have the highest value — these are the only true must-pull banners. Third, sidegrade banners (second or third debut for an existing operative) are usually skippable unless you main that operative.

✓ RULES FOR FUTURE BANNERS
  • Save pulls for first-introduction banners (new element/role)
  • Skip all rerun banners (unless you missed the original)
  • Skip sidegrade debut banners for operatives you don't main
  • Rerun banners average 2.4/5.0 — not worth the opportunity cost
  • Never pull on concurrent banners — pick one and commit
  • If a banner's value is uncertain, skip it — no banner is FOMO-worthy
✗ COMMON MISTAKES
  • Pulling on every debut "just in case" this one is S-tier
  • Splitting pulls between concurrent banners and getting neither
  • Pulling for R1 on a debut when you could save for the next debut
  • Ignoring the rerun value gap — all reruns are below average
  • Letting FOMO from community hype drive pull decisions

Tip: The most valuable pull strategy going forward is simple: skip everything except first-introduction banners for new operatives or new elements. Save all pulls for the anniversary and summer patches, which historically have the highest-value banners. Between major patches, do not pull at all. This conservative strategy would have ranked in the top 10% of account value by the end of Year 1.

Summary: Of 16 limited banners in Year 1, only 3 were S-tier (Xavier Light Seeker, Sylus Execute Protocol, Rafayel Inferno Waltz). Rerun banners averaged 2.4/5.0, significantly underperforming debuts at 3.8/5.0. The worst banner (Zayne Hoarfrost Veil) had a 68% regret rate. The data supports skipping reruns, skipping sidegrade debuts, and saving for first-introduction banners. Future pull strategy: skip everything except new operative or new element debuts.
