Gacha Strategy Guide

Every Wish counts. Master the pity system, plan your pulls, and never waste a single gem.

ENTRY_#014 2026.06.29 GACHA_GUIDE

The Golden Rule: Never pull unless you can reach the next pity threshold. Partial pity is the #1 reason players quit. A limited banner with 50 pulls and no SSR is not "progress" — it's 8,000 gems spent with nothing to show for it. Save until you can guarantee the unit.

Written by Kaelen — Deepspace Hunter Station Team

Banner Types

Love and Deepspace has four banner types. Each serves a different purpose.

Beginner Banner

Cost: Special beginner tickets (free from missions).

Pity: Guaranteed SSR in 20 pulls.

Strategy: Pull immediately. The beginner banner gives your first SSR at a massive discount. Do not skip this — it determines your early game direction.

Tip: The beginner banner uses unique tickets, not standard or limited tickets. There is no reason to save them.

Standard Banner

Cost: Blue Wish Tickets (free from dailies, events, shop).

Pity: Hard pity at 70 pulls. Soft pity starts at 60. Pity carries over between standard banner rotations.

Strategy: Pull only with free blue tickets. Never spend gems here. Standard SSRs are permanent — you will get them all eventually through lost 50/50s and free tickets.

Tip: Standard banner has no rate-up. The pool includes all non-limited SSRs. You cannot target a specific operative here.

Limited Banner

Cost: Gold Wish Tickets (bought with gems, 160 gems each).

Pity: Hard pity at 70 pulls. Soft pity at 60. 50/50 system: first SSR has 50% chance to be rate-up. Lose 50/50 = next SSR guaranteed rate-up. Pity carries over between limited banners.

Strategy: This is where your gems go. Only pull on limited banners when you have 140 pulls saved (22,400 gems) — enough to guarantee the rate-up through pity + 50/50 loss.

Tip: Pity counter carries over. If you pulled 40 on one limited banner and stopped, the next limited banner starts at 40/70 pity.

Memory (Weapon) Banner

Cost: Gold Wish Tickets (same pool as character limited banner).

Pity: Same as character banner (70 hard, 60 soft). 50/50 system applies. Pity carries over between memory banners.

Strategy: Only pull for memories of operatives you already have and use. A memory without the operative is useless. Memory value depends on the operative's base strength — don't pull a memory for a B-tier operative.

Tip: Memory banners and character banners share ticket type but NOT pity. Track them separately.

Pity System Deep Dive

Hard Pity 70 pulls
Soft Pity Start 60 pulls (+rate increases per pull)
Average SSR ~63 pulls
50/50 Win Rate 50% (first SSR per banner)
Guaranteed Rate-Up 140 pulls (max)
Pity Carry-Over Yes — within same banner type
How Soft Pity Works
From pull 60 to 69, each pull increases the SSR rate by approximately 6-8%. At pull 60, the base rate of ~0.6% jumps significantly. Most SSRs drop between pull 62 and 68. Hard pity at 70 is rare — the average SSR arrives around pull 63. This means saving 70 pulls is sufficient for a "guaranteed" SSR, but saving 140 is required for a "guaranteed rate-up."

Pull Priority Framework

When deciding whether to pull on a banner, use this decision tree:

Step 1 — Do you need this operative?
Check the operative tier list. If the operative is S-tier (Xavier, Sylus), the answer is almost always yes. If A-tier (Zayne, Rafayel), check your account needs. If B-tier, skip unless you love the character.

Step 2 — Do you have enough for guarantee?
If you have 140 pulls (22,400 gems) or current pity + savings = 140, proceed. If you have less, the answer is: save until you do.

Step 3 — Do you have the team for this operative?
A new operative needs memories, supports, and a team slot. If you already have 6 operatives built for Abyss, consider whether this operative genuinely improves your account or is a sidegrade.

Step 4 — Is this a memory or character banner?
Character > memory always. A new character opens new team compositions. A memory only improves one existing team. Pull characters first, memories second.

Banner Planning Strategy

Here's the optimal banner approach for different account stages:

🆕
New Player (0-2 months)

Pull beginner banner immediately. Save all gems for the next limited character banner that features an S-tier operative (Xavier or Sylus). Do NOT pull on the standard banner. Do NOT pull on memory banners. Your goal is to acquire 2-3 strong operatives for Abyss depth.

Mid Game (2-4 months)

You should have 2-3 SSRs by now. Your next pulls should target: (1) completing a resonance pair (e.g., if you have Xavier, pull Sylus), or (2) adding a new element coverage. Skip memory banners entirely unless the memory is S-tier for an operative you already own.

End Game (4+ months)

You have all 4 operatives. Your priority shifts to memory banners. Pull for S-tier memories (Stellar Contract, Twilight Oath) to push Abyss clear times. Skip banners for operatives you don't use. Save for future power-creep releases.

Pity Tracking Guide

Track your pity across banners. Here's what every player should know:

Track Separately: Limited character banner and limited memory banner share ticket type but have independent pity counters. A pull on one does NOT affect the other.

50/50 Status: After losing a 50/50 on a limited banner, your next SSR on any limited banner of the same type (character or memory) is guaranteed rate-up. This guarantee carries over between banners. If you lost 50/50 on banner A and skip banner B, banner C still has the guarantee.

Don't Waste Guarantee: If you lost the 50/50 (guaranteed next rate-up), do not waste this on a banner you don't really want. Save the guarantee for a banner where having the rate-up dramatically improves your account. A guaranteed pull is worth 140 pulls — treat it accordingly.

Common Gacha Mistakes

Mistake #1: Pulling on standard banner with gems. The standard banner pool is permanent. You will get these SSRs through lost 50/50s and free blue tickets. Every gem spent on standard is a gem that could have been a limited SSR. Never convert gems to blue tickets.

Mistake #2: Spending partial pity. 30 pulls on a limited banner with no SSR is not "building pity" — it's burning 4,800 gems for nothing. If you can't reach the next pity threshold, do not pull. Pity only matters when it reaches 60+.

Mistake #3: Pulling for dupes as F2P. Duplicate operatives give marginal stat increases. A new operative provides new teams, new elements, and new resonance pairs. As F2P or low spender, never pull for duplicates. One copy is enough.

Mistake #4: FOMO pulling. "This banner is limited and might never return!" — every gacha game says this. Most limited banners do return. If the operative doesn't fit your account, skip. The second run will come, and by then you'll have enough savings to guarantee them.

Mistake #5: Not saving for future characters. New operatives will be released. If you spend all your savings on every banner, you'll have nothing when the next Sylus-tier operative drops. Keep a reserve of 140 pulls (22,400 gems) at all times for surprise banners.

The Bottom Line: Gacha is a resource management game inside your resource management game. Know your monthly income. Never pull without guarantee. Never spend gems on standard. Never pull for dupes. Track your 50/50 status. And most importantly — accept that you cannot have every character. Choose the ones that matter for your account and skip the rest. A focused account with 3 well-built operatives will outperform a scattered account with 5 half-built ones every single time.
