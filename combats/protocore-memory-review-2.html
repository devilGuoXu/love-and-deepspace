SSR Memory Review: Support Sets

Support, hybrid, and off-meta SSR memories — when to use them and how they fit into your build.

ENTRY_#0922026.06.30CORE_SYSTEM
Written by Kaelen — Deepspace Hunter Station Team

Support Sets Matter: While offensive sets get all the attention, support sets enable your DPS to deal damage. A well-built Zayne with Frostguard keeps your team alive through DoT phases. Never underestimate the value of survivability.

Solar Flare Set (Hybrid/All)

2-Piece Bonus: +18% ATK. 4-Piece Bonus: +15% All-Type DMG. Rating: A-Tier (Universal). The most flexible set in the game. It works on every operative and in every content type. The 4-piece bonus is unconditional — no activation requirements. Use this as a filler set if you don't have character-specific sets. It's never the best choice, but it's never the wrong choice.

Void Walker Set (Sylus/Flex)

2-Piece Bonus: +25% Energy Recharge. 4-Piece Bonus: +18% Dark DMG on ultimate. Rating: B-Tier (Situational). A transitional set for Sylus before Dark Champion. The Energy Recharge is valuable but the 4-piece bonus is conditional. Use this if you have good substat rolls on Void Walker pieces but haven't completed Dark Champion.

Icebreaker Set (Zayne DPS)

2-Piece Bonus: +15% Frost DMG. 4-Piece Bonus: Freeze duration +1s, frozen targets take +20% damage. Rating: B-Tier (Situational). If you build Zayne as pure DPS instead of hybrid, this is his set. The freeze extension is valuable in coordinated co-op but less impactful in solo play. Only build this if you have a second support operative on your team.

Wildfire Set (Rafayel Transition)

2-Piece Bonus: +18% ATK. 4-Piece Bonus: CRIT hits deal +25% DMG for 3 seconds. Rating: B-Tier (Transition). A transitional set for Rafayel before Inferno Blaze. The conditional damage boost is inconsistent without high CRIT rate. Use as a stepping stone to Inferno Blaze.

Transition Strategy from B-Tier to S-Tier Sets

Transitioning from transitional sets to optimized sets requires a structured approach to avoid wasting resources. Phase 1: farm and level a transitional set (Void Walker for Sylus, Wildfire for Rafayel, Icebreaker for Zayne) to level 40-50 while collecting pieces for the target S-tier set. Phase 2: when you have collected three of the four needed S-tier set pieces, stop investing in the transitional set and begin saving enhancement materials. Phase 3: the moment you complete the 4-piece S-tier set, level it directly to 50+ using the saved materials. This phased approach minimizes the period where you are using a partial set with no 4-piece bonus.

The worst mistake during set transition is leveling a transitional set to 60+ and then replacing it immediately with an S-tier set at level 1. The materials spent on the transitional set are largely wasted because the salvage return for level 60 memories is only 40% of invested materials. Level transitional sets to 50 maximum — the cost to go from 50 to 60 is roughly equivalent to the cost of taking a fresh S-tier set from 1 to 40, and the performance difference between level 50 and level 60 is only about 5%. Save those materials for your final set.

Multi-Account and Team Building Strategy

Solar Flare's universal nature makes it the ideal set for building depth across multiple teams. When you are building your third or fourth Abyss team, you likely do not have enough character-specific set pieces to outfit all operatives optimally. Solar Flare fills this gap efficiently — one Solar Flare set can be shared between operatives because the 4-piece bonus applies to everyone equally. The ATK% and All-Type DMG bonuses work identically on Xavier, Sylus, Zayne, and Rafayel, making the set fully transferable between teams.

The optimal allocation of set types across four Abyss teams is: Team 1 — character-specific S-tier set (Light Seeker, Dark Champion). Team 2 — character-specific A-tier set (Inferno Blaze, Frostguard). Team 3 — Solar Flare set (universal). Team 4 — transitional set or best available pieces. This allocation ensures that your two strongest teams have optimized damage output while your third team has consistent performance and your fourth team uses whatever resources remain. As you collect more character-specific sets, promote them upward through this hierarchy.

Key Insight: Solar Flare 4-pc is the best "I don't know what to build" set. It gives unconditional damage to any operative. Every account should have at least one Solar Flare set as a backup option. It's particularly valuable for your third or fourth team where character-specific set investment is wasteful.

Summary: Solar Flare is the king of universal sets. Other support sets are transitional or situational. Build character-specific sets first, then Solar Flare for flex teams. Avoid building niche sets (Icebreaker DPS Zayne, Wildfire) unless you have spare resources.
