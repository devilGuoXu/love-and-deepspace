Banner Value Analysis Framework

How to evaluate any banner — calculate value, compare opportunity cost, and know when to pull or skip.

ENTRY_#0472026.07.01GACHA_ANALYSIS

Framework vs Opinion: This is not a tier list for specific banners. This is a methodology you can apply to ANY banner. Learn the framework once, evaluate every banner yourself. Be your own TC.

The Four Factors

Every banner is evaluated on four axes: Set Power (how strong is the memory's set bonus?), Roster Fit (do you need this element/operative?), Replacement Cost (how hard is this to replace?), Future Value (will this age well?). Score each factor 1-5, then average. A score of 4+ is pull, 3-4 is consider, below 3 is skip.

Set Power (Weight: 40%)

The most important factor. Compare the banner's set bonus to existing alternatives. A set that provides +30% CRIT DMG on resonance (like Light Seeker) scores 5. A set that provides +10% ATK scores 2. A set that provides a unique mechanic (like Dark Champion's execute refund) scores 5. A set that provides generic stats scores 1-2. If the set is best-in-slot for its operative, that's a 5.

Benchmark formula: Compare the 4-pc bonus to the next-best alternative. If this set is 20%+ better, score 5. If 10-20% better, score 4. If comparable (+5%), score 3. If worse, score 1-2.

Roster Fit (Weight: 30%)

Do you have the operative this set is designed for? If yes, do you have a usable set for them already? If you play Xavier and don't have Light Seeker, this is a 5. If you already have a good set for Xavier, this is a 3. If you don't play Xavier at all, this is a 1.

Element coverage matters: If this banner fills a missing element in your roster, add +1 to the score. If it duplicates an element you already have 2+ operatives for, subtract -1.

Replacement Cost (Weight: 15%)

How hard is this memory to replace? A limited SSR that cannot be obtained outside its banner period is a 5 — if you skip it, you may never get it. A standard-pool SSR is a 3 — you can get it from spooks or selector tickets. An SR is a 1 — you'll get it dozens of times naturally.

Future Value (Weight: 15%)

Will this set age well? Universal sets (like Solar Flare, ATK% bonuses) age well — score 4-5. Character-specific sets that are best-in-slot for a meta operative score 3-4. Niche sets score 1-2. If the set is likely to be powercrept within 3 patches, score 1.

Example Calculation: Light Seeker set: Set Power 5 (best-in-slot for Xavier), Roster Fit 4 (if you main Xavier), Replacement Cost 5 (limited), Future Value 4 (burst meta ages well). Weighted: (5×0.4)+(4×0.3)+(5×0.15)+(4×0.15) = 2+1.2+0.75+0.6 = 4.55 → Pull.

Summary: Set Power (40%) > Roster Fit (30%) > Replacement Cost (15%) = Future Value (15%). Score each 1-5, apply weights. 4+ pull, 3-4 consider, below 3 skip. Re-evaluate every banner — don't pull on autopilot.
