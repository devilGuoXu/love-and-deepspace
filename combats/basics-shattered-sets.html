Shattered & Engraved Sets

Side-grade memory sets — Shattered (dodge→ATK) and Engraved (shield→DEF explosion). Niche but powerful.

ENTRY_#0702026.07.02SETS

Why These Matter: 95% of the time, standard memory sets outperform these side-grades. But in the right situation, Shattered and Engraved sets can outperform standard builds by 20-30%. Know when to use them.

Shattered Set (Dodge → ATK)

The Shattered set converts perfect dodge timing into offensive power. 2pc Bonus: Increases dodge window by 0.1s (minor but noticeable). 4pc Bonus: After a perfect dodge, gain +40% ATK for 5 seconds. This is the core of the set. How it works: Perfect dodge → +40% ATK → massive damage window. The 5-second window is enough for 1-2 skills and a few basic attacks. Cooldown: The effect has a 10-second internal cooldown. You cannot chain perfect dodges for infinite uptime. Effective uptime: Against aggressive bosses, you can maintain ~33% uptime on the +40% ATK buff. Against passive bosses, the set is useless. Best on: Operatives with fast attack animations that can maximize the 5-second window. Dodging and attacking quickly is key.

Engraved Set (Shield → DEF Explosion)

The Engraved set turns defensive actions into offensive power. 2pc Bonus: Increases shield strength by 15%. 4pc Bonus: When a shield expires or breaks, deal 200% DEF as damage to nearby enemies. This is the core mechanic. How it works: Apply shield → shield duration ticks down or is broken by enemy damage → explosion deals DEF-based damage. The explosion is AoE and scales entirely off DEF. Important: The explosion damage is fixed — it does not benefit from ATK, CRIT, or damage bonuses. It scales purely from DEF. This means you build full DEF on the Engraved set user. Best on: Zayne (has inherent shield synergy). Tanky operatives with high base DEF. Support operatives that can afford to build DEF instead of ATK.

Important Limitation: Engraved set damage is capped by a 2-second per-target cooldown. The explosion hits each enemy at most once every 2 seconds. Against single-target bosses, this means you get one explosion per shield. Against groups, the AoE can be very strong.

When to Use Each

Shattered set is good when: You are fighting aggressive bosses with clear telegraphed attacks (Titan, Crystal Phantoms). You are confident in your dodge timing (consistency matters). Your operative has fast animations that can capitalize on the 5-second window. You are on attack (PvP) and need burst damage. Shattered set is bad when: The boss is passive (few dodge opportunities). The boss has undodgeable attacks. You are not confident in your dodge timing. Engraved set is good when: You are using Zayne (shield synergy). You need AoE damage. You are building a tanky team. You are on defense (PvP) and want sustain + damage. Engraved set is bad when: You have no shield source in your team. You are fighting single-target bosses (the 2s cooldown limits damage). You need consistent DPS rather than burst.

Build Requirements

Shattered set build: Standard DPS build but with an emphasis on skills that can be used quickly after a dodge. Recommended substats: CRIT Rate > CRIT Damage > ATK% > Energy Regen. Protocore priority: ATK% main stat on Solar/Lunar. CRIT rate on slot 4/6. CDMG on slot 5/6. Engraved set build: Pure DEF build. Ignore ATK, CRIT, and all offensive stats. Recommended substats: DEF% > HP% > Energy Regen > flat DEF. Protocore priority: DEF% on all slots that can roll it. HP% for survivability. Important: Engraved set does not benefit from CRIT or DMG bonuses at all. Do not build CRIT on an Engraved user — it is completely wasted.

Best Matchups

Shattered set is best against: Titan (phase 1 dodge windows are frequent and telegraphed). Crystal Phantoms (all attacks are dodgeable). Sylus Phantom (his slow scythe swings are easy perfect dodge targets). Engraved set is best against: Crowd content (multiple enemy waves). Co-op bosses (shield explosion hits both boss and adds). PvP defense (sustained shield pressure + unexpected burst). Any content where you need a tank to contribute damage.

Team Compositions

Shattered team: Operative A (main DPS with Shattered) + Operative B (burst damage) + Support (healer/shielder). The Shattered DPS does burst damage after every perfect dodge. Engraved team: Zayne (tank with Engraved) + DPS + Support. Zayne applies shields, draws aggro, and the explosion damages everything nearby. Both sets in one team: Shattered DPS + Engraved tank + Healer. The Shattered DPS handles single-target burst, the Engraved tank handles AoE and survivability. This is a strong but gear-intensive composition.

Verdict: 95% of the time, standard 4pc damage sets are better. Shattered and Engraved are side-grades that shine in specific situations. Invest in them only after you have standard sets built, or if you main Zayne (Engraved) or love perfect dodge gameplay (Shattered). They are fun to play, but not meta-mandatory.

Summary: Shattered set = perfect dodge → +40% ATK for 5s. Engraved set = shield → 200% DEF explosion. Both are side-grades — better than standard sets in niche situations, worse in general. Shattered excels against aggressive bosses. Engraved excels with Zayne and in AoE content. 95% of players should use standard sets. These are for min-maxers and enthusiasts.
