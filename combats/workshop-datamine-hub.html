What Dataminers Find

Why Datamine? The Love and Deepspace community does extensive datamining to uncover hidden game mechanics that the UI does not display. Exact skill multipliers, hitbox data, enemy stats, protocore drop tables, and soon-to-release content are all buried in the game files. This hub aggregates the most trusted sources and explains how to use their findings.

Official patch notes give you direction. Datamined data gives you precision. When a patch note says "increased Xavier's skill damage," the datamine tells you the old multiplier was 185% and the new one is 210%. That 25% difference translates to specific DPS changes you can calculate before logging in. Players who follow datamine sources consistently make better build decisions because they base their choices on exact numbers rather than vague descriptions.

The game client ships with data files that contain every number the game engine uses: damage formulas, drop probabilities, enemy stat blocks, memory growth curves, and even unreleased content flagged for future patches. Dataminers extract and decode these files using tools that parse Unity asset bundles and reverse-engineer the serialized data structures. The result is raw, unfiltered game information that the developers never intended players to see directly.

Not all datamined information is equally useful. Some categories — like skill multipliers and protocore stat ranges — are directly applicable to build optimization. This hub grades each category by reliability and practical value so you know where to focus your attention.

Categories of Data

Datamined information falls into several distinct categories. Each requires different tools to extract and different knowledge to interpret. Here is what the community regularly discovers.

Skill Multipliers
Exact damage percentages for every skill at every level. The game stores base multiplier, scaling stat coefficient, and per-level growth rate in structured JSON files. This data reveals which skills scale best with ATK, which have hidden breakpoints, and how rank bonuses actually modify damage.
Format: JSON with nested skill treesReliability: 99% — confirmed against in-game testing
Hidden Stats
Enemy DEF, elemental RES, stagger thresholds, poise values, and hitbox dimensions. The UI shows none of these. Datamining reveals that weekly bosses have specific elemental resistances that change how you should build your team. For example, the Frost Tyrant has 40% bonus Ice RES, making raw ATK builds better than Ice DMG builds against it.
Format: Binary asset tablesReliability: 90% — some values confirmed, others extrapolated
Drop Rates
Exact probabilities for domain drops, event rewards, and protocore stat distributions. The game weight system assigns different probabilities to each substat and main stat combination. Dataminers have shown that CRIT Rate and CRIT DMG have lower weight than flat DEF, confirming what players suspected — the game weights desirable stats lower.
Format: Weight tables with probability entriesReliability: 85% — confirmed with large sample crowd-sourced data
Future Content
Unreleased memories, outfits, events, and story chapters flagged in asset bundles. These entries appear when assets are added to the client before their official release. Dataminers find placeholder text, model files, and skill descriptions for content that will ship 1-2 patches ahead. This data is useful for planning gem savings but always subject to change.
Format: Asset bundle filenames + partial descriptorsReliability: 70% — content often changes before release

Trusted Sources

Not all dataminers are equally reliable. Some have years of experience decoding game files; others post unverified extracts that turn out to be wrong. Here are the most trusted sources in the Love and Deepspace community, vetted by accuracy and consistency across multiple patch cycles.

Specializes in extracting and validating skill multipliers, animation frame data, and optimal rotation DPS. Maintains a public spreadsheet of every character's skill values across all ranks. Cross-references every datamine point with in-game recording analysis. Reliability: 98%.
SOURCE B VERIFIED
Drop Rates & Economy
Focuses on protocore drop tables, domain reward probabilities, and gem economy projections. Uses both client-side weight extraction and large-scale crowd-sourced drop logging. Published the definitive study on substat weight distribution. Reliability: 95%.
SOURCE C LEAKS
Future Content & Lore
Tracks unreleased assets, memory descriptions, outfit models, and story text found in patch preloads. Provides early warning of banner schedules and event types. Content is subject to change; cross-reference with official announcements. Reliability: 75% for specifics, 90% for general direction.
SOURCE D TECHNICAL
Game Files & Technical Data
Extracts and documents the underlying game engine parameters: enemy stat blocks, stagger thresholds, AI behavior flags, and networking data. Publishes raw file extracts with detailed annotations. Essential for understanding game mechanics that the UI completely hides. Reliability: 92%.

How to Evaluate a New Source: Check their track record across at least two patch cycles. Do they post raw data alongside their conclusions? Do they correct errors publicly? A trustworthy dataminer admits when they were wrong. Avoid sources that only post hype-worthy leaks without showing their work. The best dataminers also explain their methodology so you can verify the results yourself.

How to Read Datamine Outputs

Raw datamine data looks intimidating but follows predictable patterns. Once you understand the structure, you can extract the information you need without a technical background.

JSON Skill DataBase multiplier = skill damage before ATK scaling. Multiply by (1 + scaling_ratio * total_ATK) for base hit. Add level_growth per skill level. Example: base 2.85x, 0.65 scaling, 2000 ATK = 2.85 * (1 + 0.65 * 2000/100) = 2.85 * 14 = 39.9x ATK at level 1.
Protocore Stat RangesEach rarity (R, SR, SSR) has min/max values for every stat. SSR CRIT Rate main stat rolls between 8.5% and 12.4% at level 0, growing to 18-26% at +15. Substats roll 60-100% of the max possible for their rarity. Higher rarity = higher floor and ceiling.
Enemy Stat BlocksHP, ATK, DEF, elemental RES, stagger threshold, poise recovery rate. Elemental RES values are percentages applied after DEF reduction. A boss with 30% Fire RES takes 30% less Fire damage, making elemental choice a 30% damage swing.
Memory Growth CurvesEach memory has base stats and per-level stat growth coefficients. Flat ATK, HP, and DEF growth is linear. Percentage bonuses from set effects apply after base + level scaling. This data tells you which memories give the best stat-per-level ratio.
Stagger ThresholdsEnemies have hidden stagger HP pools that refill over time. Each hit depletes a percentage based on the skill's stagger modifier. Heavy attacks deal 3x stagger damage compared to light attacks. Datamined threshold values let you calculate exactly how many hits to stagger.

Reading Tip: Most datamine JSON files use the same naming conventions. "base_multiplier" or "base_ratio" is always the skill's damage coefficient. "scaling_stat" points to the character stat used for bonus damage. "level_growth" or "per_level" is the additive increase per skill level. Once you learn these six key fields, you can read any skill datamine in the game.

Using Datamined Data for Builds

Data without application is trivia. Here is how to turn datamine outputs into concrete build decisions that improve your gameplay.

1
Skill Multiplier Optimization
Compare exact damage per animation frame using datamined multipliers and frame data from Source A. A skill might show 250% in the UI but has a 2-second animation, while another shows 180% with a 1-second animation. The second skill has higher DPS. Use multiplier data to build your rotation around the skills with the best damage-per-frame ratio.
2
Farming Efficiency Planning
Source B's drop rate data tells you that CRIT Rate planetary protocores have a 4.2% drop chance per run. Expected stamina per usable piece: 1,200 stamina. Plan your weekly domain farming around the protocores you actually need. Do not farm on days when the rotating domain does not drop the set you want — wait for the correct rotation.
3
Elemental vs Raw ATK Decision
Enemy RES values from Source D tell you which element each boss resists. Against the Frost Tyrant (40% Ice RES), a pure Ice DMG build loses 40% of its damage. Raw ATK with neutral element outperforms elemental stacking. Against the Inferno Colossus (0% Fire RES, 25% Ice weakness), elemental stacking is optimal. Check the RES table before building for a specific boss.
4
Pre-Farming for Future Content
Source C's future content leaks reveal upcoming memory sets and their stat profiles. If a leaked memory favors CRIT DMG over CRIT Rate, you can start farming CRIT DMG protocores now. Leak-based preparation gives you a 2-3 week head start on new metas. Always keep your existing gear — leaks can change before release.

Identify your target

Community Data Projects

The best datamined data is validated by community crowd-sourcing. These ongoing projects need your contribution to improve their accuracy and completeness.

PROTOCORE DISTRIBUTION SPREADSHEET
12,000+ drops logged
A shared spreadsheet where players log every protocore drop: domain, set, slot, main stat, substats, and enhancement results. The aggregated data confirms (and sometimes contradicts) the datamined weight tables. Current dataset: 12,400 entries from 340 contributors. Goal: 20,000 entries for statistical significance.
DOMAIN DROP LOG
Crowd-sourced reward tracker
Logs every domain run reward: protocore rarity, set type, and quantity. Tracks domain rotation schedules and identifies the most efficient farming days. Latest finding: Tuesday's domain rotation drops 8% more SSR protocores than Sunday's rotation, based on 5,200 logged runs.
ROTATION DPS DATABASE
Community-recorded rotation times
Players submit video recordings of their optimal rotations against the training dummy. The database calculates time-to-kill, DPS, and skill usage frequency. Used to validate datamined skill multipliers against real in-game performance. Over 800 rotation recordings analyzed.
ENEMY STAT COMPENDIUM
Every enemy in the game cataloged
Combines datamined enemy stat blocks with player-sourced observations. Includes HP values per difficulty level, elemental RES values, stagger thresholds, and attack pattern notes. The compendium covers all 47 enemy types across all difficulty tiers.

How to Contribute: Most projects accept submissions through Discord bots or Google Forms. Record your domain runs with a screenshot of the reward screen, log your protocore drops with the in-game details visible, and submit your rotation videos to the DPS database. Even 10 entries help. The more data the community collects, the more accurate the aggregate results become for everyone.

Responsible Use Guidelines

Datamining is a powerful tool that requires responsible handling. The Love and Deepspace community has developed norms around how datamined information should be shared and used. Following these guidelines keeps the community healthy and respectful.

Gameplay OptimizationAllowed. Using datamined skill multipliers and drop rates to make better build decisions is the primary purpose of this hub. The developers have not objected to gameplay-focused datamining.
Content TheftNot allowed. Extracting and redistributing game assets — models, textures, voice lines, story text — as your own content is copyright infringement and damages the developers' work.
Future Content SpoilersAlways warn before sharing. Use spoiler tags, clearly label leak content, and give readers the choice to see or skip. Not everyone wants to know about upcoming banners before the official announcement.
Respect Hidden MechanicsSome mechanics are intentionally hidden by the developers to preserve discovery and mystery. Sharing that an enemy has a specific stagger threshold is fine. Extracting and distributing unreleased story text crosses a line.
Prepare, Don't ComplainUse leaked data to prepare for upcoming content, not to complain that content is "too easy" because you pre-farmed, or that banner announcements are "boring" because you saw them three weeks ago.
DO use datamined data to optimize your builds and farming
DO credit the dataminers who extracted the data
DO warn before sharing future content information
DO NOT redistribute game assets as your own work
DO NOT post unmarked spoilers in community spaces
DO NOT harass developers about leaked content

The datamining community and the developers exist in an unspoken truce. Dataminers focus on gameplay data that helps players. Developers focus on creating content. As long as both sides respect each other's boundaries, the truce holds. Breaking these guidelines risks souring the relationship and could lead to technical countermeasures that make datamining harder for everyone.
