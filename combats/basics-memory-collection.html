Memory Collection Guide

Every memory, every source, every priority. Complete catalog and farming strategy for the collection-driven hunter.

ENTRY_#018 2026.06.29 COLLECTION

Core Insight: Memories are the primary progression system in Love and Deepspace. Each operative can equip 6 memories, and your total memory power determines your Abyss readiness. Understanding which memories exist, how to get them, and which to prioritize is the difference between a strong account and a scattered one.

Written by Kaelen — Deepspace Hunter Station Team

Memory Rarity & Types

SSR
5-star. Best stats, unique effects. Obtained from gacha (limited + standard). Base stat value: 100%.
SR
4-star. Good filler stats. Obtained from gacha, events, and shops. Base stat value: 75% of SSR.
R
3-star. Low stats. Mostly used for early game. Base stat value: 50% of SSR.

Each memory also has an element (Light, Dark, Frost, Flame, Lightning, Water), a set (Solar, Permafrost, Tidal, Shadow), and a signature operative (the operative it's designed for). Using a memory on its signature operative gives bonus stats.

Memory Sources

Limited Gacha Banner
Primary source of new SSR memories. Rate-up SSR has 50% chance. 140 pull hard guarantee. Limited memories may return in rerun banners.
Standard Banner
Permanent SSR pool. Pull with free blue tickets. All standard SSRs are added to the pool permanently. Can also spook you on limited banner 50/50 losses.
Event Shop
Limited-time event shops often sell 1 SSR memory shard box and 1 SR memory. Always buy the SSR shard box — it's the cheapest SSR acquisition method at ~3,000-5,000 event currency.
Crew Shop
SSR memory shards for crew coins. Buy daily. It takes ~2 months to assemble one SSR from shop shards.
Achievement Rewards
One-time rewards for collection milestones (e.g., collect 10 SR memories, ascend 3 memories to level 60). Good source of early SR memories.
Battle Pass / Monthly Pass
Paid track rewards include memory shards, selection boxes, and crafting materials.

Collection Priority

Not every memory is worth collecting immediately. Here's the priority system:

Tier S — Immediate Priority: Stellar Contract (Xavier), Twilight Oath (Sylus). These S-tier memories transform their operative. If you see them on a banner, pull to guarantee.

Tier A — High Priority: Permafrost Covenant (Zayne), Inferno Waltz (Rafayel). Strong memories that significantly improve performance. Pull if you have resources.

Tier B — Medium Priority: Standard banner SSRs for operatives you use. Any SSR is better than no SSR, but don't spend gems chasing standard-pool memories.

Tier C — Low Priority: Memories for operatives you don't use. They'll come naturally through off-rate pity and event shops.

Shard Farming Strategy

SSR memory shards are the long-term collection game. Here's how to optimize:

Crew Shop — Daily Reset
Cost: 200 crew coins per shard. Limit: 2 per day. Target: any SSR you're building. This is the most consistent shard source. Log in daily, donate to crew, buy shards. 60 shards = 1 SSR. At 2/day = 30 days per SSR.
Event Shop — Per Event
Cost: ~3,000-5,000 event currency. Limit: 10 shards per event. Target: SSR of your choice. Always buy these before spending currency on materials.
Abyss Shop — Monthly Reset
Cost: Abyss tokens. Limit: 5 shards per month. Target: SSR memory you're closest to completing.

Collection Rule: Never spread shards across multiple SSRs. Focus on one SSR at a time. Use all crew coins, event currency, and Abyss tokens on the same target until it's complete. A completed SSR is worth infinitely more than 10 partial SSRs.

Common Mistakes

Mistake #1: Not buying crew shop shards daily. 200 crew coins per day = 1 SSR every 30 days. Missing a week = 14 shards lost = 25% of a week's progress. Crew shards are the most consistent and cheapest SSR source in the game.

Mistake #2: Spreading shard purchases. Buying shards for Xavier one day, Sylus the next, Zayne the third = 0 completed memories. Focus until completion, then move to the next.

Mistake #3: Ignoring SR memories. "Only SSRs matter" is expensive advice. An SR memory at level 60 with the correct element outperforms an SSR at level 30 with wrong element. Collect and level SRs for color coverage, especially in early-mid game.

The Bottom Line: Memory collection is a marathon. Pull for S-tier memories on limited banners. Buy crew shards daily. Focus one SSR at a time. Don't ignore SRs for color coverage. Accept that full SSR collection will take 6+ months as F2P — and that's okay. A focused collection of 6 well-chosen SSRs clears more content than a scattered collection of 12 partial ones.
