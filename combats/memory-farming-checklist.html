Memory Farming Checklist

A comprehensive farming checklist to optimize your daily and weekly memory progression without wasting stamina or resources.

ENTRY_#MEM_102026.07.02FARMING

Core Philosophy: Memory farming is a marathon, not a sprint. Consistent daily farming beats sporadic heavy farming every time. This checklist helps you build sustainable habits that maximize long-term account growth.

Daily Checklist

These tasks reset every day and should be completed before your stamina caps. 1. Spend all stamina on protocore dust domains. Protocore dust is the universal bottleneck. Every other resource (XP, gold, ascension materials) has alternative sources — protocore dust does not. Priority: Protocore Dust Domain > XP Domain > Gold Domain. 2. Claim daily login rewards. Includes stamina potions, gold, and random materials. The 7-day login cycle gives SSR shards on day 7. 3. Send and receive friend gifts. 10 stamina per gift, max 30 friends. 300 stamina/day if fully utilized. This is the single biggest free stamina source. 4. Complete daily bounties. 3 bounties per day. Rewards: affinity XP, gold, and memory enhancement materials. Bounties take 5 minutes. Do not skip them. 5. Use your 3 free Sweep attempts. Sweep stages you have already cleared for instant material collection. Use on the highest available Protocore Dust stage. 6. Check the Crew Shop. Buy SSR memory shards (2 per day for 1,200 crew coins). This is the most consistent SSR acquisition method for F2P players.

Weekly Checklist

These tasks reset weekly and require dedicated time. 1. Clear Weekly Bounties. 5 weekly bounties. Higher rewards than daily bounties including diamonds and SSR memory boxes. 2. Complete Crew Boss. 3 attempts. Coordinate with crew for maximum damage. Rewards scale with performance. 3. Farm Abyssal Chaos floors. Weekly reset. Each floor gives memory materials, diamonds, and protocore boxes. Prioritize floors you can clear in under 5 minutes for efficiency. 4. Buy from the Shop. Weekly reset stocks. Buy: limited pulls for stardust (5 per month), gold for gold tickets, any SR memory boxes if you need specific set bonuses. 5. Claim Battle Pass rewards. If you have the paid pass, collect the SSR memory box and other high-tier rewards. The free pass also gives useful materials. 6. Review your memory inventory. Identify which memories need leveling, which can be used as upgrade fodder, and which set bonuses you're missing. Plan next week's domain priority accordingly.

Memory Leveling Priority

Resources are finite. Spend them in this order: 1. SSR main DPS memories to level 70. This is the biggest power spike per resource spent. One well-invested SSR carries your account. 2. SSR support memories to level 60. Resonance skills and set bonuses matter more than base stats for supports. 3. Key SR memories to level 50. Only the A-tier SRs (Stellar Guard, Frost Guardian, Ember Gaze, Shadow Weaver). 4. Fill out set bonuses with level 40 SSR/SR memories. Set activation > individual memory stats. 5. Do not level any memory past 70 unless you have a full team of 70s. The cost to go from 70 to 80 is equivalent to taking a memory from 1 to 70. Prioritize breadth over depth early on.

Stamina Management: Your stamina generates at 1 per 6 minutes = 240 stamina/day. Daily login + friend gifts add ~360 stamina/day. Total: ~600 stamina/day. Spend this as: 300 on Protocore Dust, 200 on XP/Gold domains, 100 on event shops (during events). Never let stamina sit at max. If you cannot play for a day, at least log in for 2 minutes to claim friend gifts and spend stamina on Sweeps. Wasted stamina is wasted account progress.

Event Farming Priority

During limited events, adjust your farming: Event Currency Shop: Always buy SSR shards first. Then limited pulls, then protocore boxes, then XP/gold. Skip cosmetic items unless you have excess currency. Event Story Stages: Clear all stages once for first-clear rewards. Then focus on the highest-efficiency repeatable stage for event currency. Double Drop Events: When double protocore dust is active, spend all stamina pots saved from the previous month. A well-prepared player can get 2-3 weeks worth of dust in one double-drop weekend. Event Boss Fights: Do your 3 daily attempts every day. Even if the rewards seem small, they add up over the event duration.

Summary: Daily: spend stamina on protocore dust, claim login, send friend gifts, do bounties, Sweep 3 times, buy crew shop SSR shards. Weekly: clear bounties, do crew boss, farm abyssal chaos, buy shop items, plan next week. Level priority: SSR DPS to 70 > SSR support to 60 > SR to 50 > fill sets at 40. During events: prioritize event currency > SSR shards > pulls > protocore. Save stamina pots for double drop events. Consistent daily farming is the key to account growth.
