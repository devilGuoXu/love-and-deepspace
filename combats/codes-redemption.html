Code Redemption Guide

How to redeem promo codes in Love and Deepspace across all platforms. Troubleshooting tips for common redemption errors.

ENTRY_#CDE_022026.07.02REDEMPTION

Core Rule: Promo codes are redeemed in-game through the Settings menu. The redemption system is account-bound — rewards go to the account that redeemed the code. You cannot redeem the same code twice on the same account.

Step-by-Step Redemption

Follow these exact steps to redeem any promo code: Step 1: Launch Love and Deepspace. Wait for the main menu to fully load. Step 2: Tap your avatar icon in the top-left corner (Account menu). Step 3: Tap the Settings gear icon. Step 4: Scroll down to the "Account" section. Step 5: Tap "Redeem Code." A text input box appears. Step 6: Enter the code exactly as shown. Codes are case-sensitive — uppercase letters must be uppercase, lowercase must be lowercase. Do not include spaces before or after the code. Step 7: Tap "Confirm." A success message appears if the code is valid. Step 8: Open your in-game mailbox (envelope icon on the main menu screen). Step 9: Claim the rewards from the system mail. Rewards are added to your inventory immediately upon claiming. Step 10: Verify the rewards by checking your diamond count, item inventory, or any exclusive cosmetics.

Platform-Specific Notes

iOS: Same steps as above. No special requirements. If the code input box does not appear, check that your game is updated to the latest version. Android: Same steps. Android users may also redeem codes through the official website using their account UID. This is useful if the in-game redemption is bugged. PC (Emulator): Same steps. Some emulators have keyboard input issues — use the on-screen keyboard to enter codes instead of the physical keyboard. PC (Official Client): If available in your region, the PC client supports code redemption through the same Settings menu. The PC client also supports copy-paste for easier code entry. Important: The redemption menu location is identical across all platforms. If you cannot find it, check that your game version is up to date. Older versions may have the redemption option in a different menu location.

Troubleshooting

Error: "Code Invalid" — The code has expired, reached its global redemption limit, or was entered incorrectly. Double-check for typos, case sensitivity, and extra spaces. If the code is from a recent source, check social media to confirm it is still active. Error: "Already Redeemed" — You have already used this code on this account. Code redemption is one-time per account. Error: "Network Error" — Your internet connection is unstable. Switch to a stable Wi-Fi connection or mobile data and try again. Error: "Region Locked" — The code is only available for specific servers (Global, CN, JP, KR). Check which server the code was released for. Codes from the CN server will not work on Global accounts. Error: "Account Level Too Low" — Some codes require a minimum account level (typically level 5). Level up by completing story stages and try again. Missing Rewards: If the code was accepted but rewards are not in your mailbox, wait 5-10 minutes and check again. If rewards still do not appear, contact customer support with a screenshot of the successful redemption message.

Pro Tips: (1) Create a text file on your phone with commonly used codes. Copy-paste is faster than typing. (2) If a code is "expired" for you but others say it works, try logging out and logging back in. Some codes are tied to login sessions. (3) Do not close the game immediately after redemption. Wait for the mail to arrive. (4) Codes from livestreams often have a 24-hour redemption window starting from the livestream end time. Set a timer. (5) Use the official website redemption option if available in your region — it is sometimes more reliable than in-game. (6) If a code fails, try restarting the game completely before attempting again. A full restart clears cached session data that can interfere with redemption.

Web Redemption Method

Some regions support web-based code redemption. Visit the official Love and Deepspace website. Log in with your account credentials. Navigate to the "Rewards" or "Redeem Code" section. Enter your UID (found in Settings > Account > UID). Enter the promo code. Confirm. Rewards are sent to your in-game mailbox. The web method is useful for: (1) Players whose in-game redemption is bugged. (2) Redeeming codes while away from the game. (3) Bypassing platform-specific issues. (4) Asia server players (web redemption is more reliable for Asia servers). The web method is not available in all regions. Check the official website for your specific server.

Summary: Redeem codes in-game through Settings > Account > Redeem Code. Enter codes exactly as shown (case-sensitive). Platform-specific differences are minimal — the menu is identical across iOS, Android, and PC. Common errors: invalid (expired/limit reached), already redeemed, network error, region locked. Troubleshoot by checking code validity, restarting the game, or using web redemption. Always claim rewards from the mailbox after successful redemption. Bookmark the official code redemption page for the fastest access.
