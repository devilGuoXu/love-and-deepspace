1.0 Launch Era (Jan-May 2025)

The launch era established the foundational event template: a story chapter with branching dialogue, a battle stage track with 5-10 difficulty levels, an event shop with currency earned from battles, and login bonuses running alongside. These events were short (7-10 days), had modest shop inventories (15-20 items), and offered 300-500 premium currency as total rewards. The first event offered only 300 gems total — a far cry from current standards.

Launch events were conservative in scope. The developers were testing engagement patterns and reward sensitivity. Event shops had high-value items (pull tickets, SSR memory shards) gated behind the highest difficulty stages, forcing players to invest in their rosters to clear content. This created frustration for newer players who could not access the best rewards. The feedback from this era shaped the tiered reward systems we see today.

Mid-Year Transition (Jun-Dec 2025)

Mid-2025 brought significant format innovations. Events expanded to 14-day durations with larger shop inventories (25-30 items). The first "double-track" events appeared, offering both a story track and a challenge battle track with separate reward pools. Premium currency rewards increased to 500-700 per event. The introduction of event-exclusive SSR memories (free, not gacha) was the single biggest quality-of-life improvement — these events became the highest-priority content overnight.

The mid-year also saw the introduction of minigame events (beach volleyball, photography contests) that diversified the event loop beyond pure combat. These events were controversial — some players loved the variety, others resented being forced to play non-combat content for rewards. The developers responded by making minigame rewards supplementary rather than mandatory, a design philosophy that continues today. Event reruns also began in this period, with reduced reward pools at approximately 60% of original value.

Key transition: The introduction of free SSR memories in events was the turning point for event value. Before this, events were supplementary income. After this, events became the primary source of free SSR acquisition for F2P players. The first free SSR event ("Ocean's Embrace," July 2025) set the template that all future SSR events follow: 14 days of currency grinding to unlock a guaranteed SSR memory.

1.5-1.9 Maturation (Jan-Apr 2026)

The maturation era refined every aspect of the event system. Event shops expanded to 35-40 items with multiple currency types (event currency + challenge currency + milestone points). Premium currency rewards settled at 700-900 per event. The "event pass" system was introduced — a free track with baseline rewards and a paid track (similar to Battle Pass) with enhanced rewards. This gave whales more value from events without reducing F2P rewards.

Format specialization emerged in this period. Story events focused on narrative depth (fully voiced, animated cutscenes). Challenge events focused on combat difficulty (leaderboard rankings, title rewards). Minigame events became standalone side-content rather than being part of larger events. The developers also introduced "catch-up mechanics" — if you joined an event late, you could spend stamina potions to catch up on currency, reducing FOMO for busy players.

2.0 Modern Era (May 2026-Present)

The 2.0 update redefined the event system entirely. Events now run 14-21 days with shop inventories of 45-50 items. Premium currency rewards range from 800-1200 gems per event. The "event pass" system became standard on all major events, with the paid track offering SSR memory dupes and exclusive cosmetics. Event currency earning rates increased by approximately 25% compared to pre-2.0, making shops easier to clear.

The most significant 2.0 innovation is the "Multi-Stage Event" format — events that evolve over their duration. Week 1 focuses on story exploration. Week 2 introduces challenge battles. Week 3 adds a co-op boss or raid component. This keeps events fresh across their entire run rather than feeling stale after day 3. The 2nd Anniversary event exemplified this format: 21 days, 3 stages, 1200 total gems, a free SSR selector, and a co-op raid boss with server-wide rewards.

Modern event benchmark: A standard 2.0-era event should offer: 4-6 pull tickets (600-900 gem value), 1 free SR memory (or SSR shards toward a free SSR), 200+ protocore dust, 100K+ gold, exclusive cosmetic item (nameplate/furniture/outfit), and enough enhancement materials to +12 one memory set. If an event offers less than this benchmark, it is below the current standard and should be evaluated carefully for time investment.

Reward Inflation Analysis

Tracking reward values across event generations reveals clear inflation patterns. Launch era: average 400 gems per event, 1 SR memory, 50K gold, 50 protocore dust. Mid-2025: average 600 gems, 1 SR or SSR shards, 100K gold, 100 dust. Pre-2.0: average 800 gems, 1 SR + SSR shards, 150K gold, 150 dust. Modern 2.0: average 1000 gems, 1 SSR memory or selector, 200K+ gold, 200+ dust. The year-over-year increase is approximately 40% in total reward value.

This inflation means that older content (reruns, archive events) offers significantly less value than new events. A rerun of a launch-era event at 60% original rewards offers only 180-300 gems — compared to 1000 from a new event. The opportunity cost of farming rerun content is substantial. Only farm reruns for exclusive memories or cosmetics you missed. Do not farm reruns for resources — new events are 3-5x more rewarding.

Strategic implication: If you have limited playtime, prioritize events in this order: (1) Anniversary/2.0 major events, (2) Seasonal events (Summer/Winter), (3) New SSR memory events, (4) New challenge events, (5) Rerun events (only for memories you missed), (6) Minigame events (skip if time-constrained). Older event formats are simply not worth your time compared to modern events.

Pattern Recognition & Predictions

Based on the evolution patterns observed, we can predict several trends for future events. Reward inflation will likely continue at 30-40% YoY — expect 1300-1500 gem events by mid-2027. Event formats will become more modular, allowing players to choose which tracks to participate in. The multi-stage format (story → challenge → co-op) will become the standard for all major events. Rerun events may receive a "2.0 refresh" with enhanced rewards to bring them up to modern standards.

The biggest open question is whether the developers will introduce an "event archive" system that lets players access past event stories permanently. The current rerun system is inefficient — players who miss an event wait 6-12 months for a rerun at reduced rewards. A permanent archive (similar to the story archive) with reduced rewards would be a major QoL improvement. Industry trends suggest this is likely within the next 6 months. Watch for announcements during the 2.5 or 3.0 updates.
