Event Shop Exchange Guide

The event shop is where your farmed currency goes to die — or to multiply your account value. Spend poorly and you lose days of stamina. Spend well and you skip weeks of farming.

ENTRY_#EVT_062026.07.02SHOP

Core Rule: Event shop currency is a limited resource. You cannot buy everything. Prioritize items that are: (1) Exclusive (cannot be obtained elsewhere). (2) Stamina-efficient (cost less stamina to farm via event than via normal stages). (3) Permanent upgrades (memories, protocores). Never spend currency on items that are cheaper or equal in normal farming, even if they seem convenient.

Tier 1 — Must Buy (Always)

SSR Memory Shards: Your #1 priority. The event SSR is exclusive for ~6 months before entering the standard pool. Getting it to R1 now saves you 6 months of waiting. Cost: ~3,000 currency for R1. Guaranteed Protocore: Event shops always sell 1 pre-rolled SSR Protocore with optimal main stat. This is the single best value in any event shop. Cost: ~1,500 currency. Equivalent to 5,000+ stamina of protocore farming. Limited Outfit / Skin: Exclusive cosmetic. Does not affect combat but never returns for 6-12 months. Cost: ~2,000 currency. Only buy if you care about cosmetics.

Tier 2 — Should Buy

Limited Pull Tickets (Deepspace Wish): Usually 5 tickets at discounted rates. Cost: ~750 currency for 5 tickets. Equivalent to 750 diamonds. Always buy these. Stamina Potions (Medium/Large): Event stamina pots are 20-30% cheaper than shop stamina pots. Buy the event-limited ones. SSR Memory Enhancement Materials (Crystal Cores): These are expensive to farm normally (45 stamina each). Event shop offers 3-5 at 50% discount. Protocore Enhancement Materials (Dust): Buy the event-discounted ones but skip the regular-priced ones.

Tier 3 — Situational

SR Memory: Buy if you haven't reached R3 on the event SR. Skip if R3+ or if you don't use the character. Character Ascension Materials: Buy only if you are actively building the character. Otherwise skip — these are farmable anytime. Gold (Credits): Only buy if you are below 100k credits and need to level a memory immediately. Credits are the most abundant resource in the game long-term. Home Decoration Items: Cosmetic only. Buy if you enjoy home decoration, skip otherwise.

Exchange Priority List

1. SSR Memory Shards (to R1). 2. Guaranteed Protocore. 3. Limited Pull Tickets. 4. Discounted Stamina Pots. 5. Crystal Cores (discounted). 6. SSR Memory Shards (to R2, if within reach). 7. SR Memory (if missing). 8. Protocore Dust (discounted). 9. Ascension Materials (if needed). 10. Gold. 11. Home Decor. 12. Regular-priced enhancement materials (skip entirely).

Pro Tip: Always do the math before the event starts. Calculate: (Event duration in days × natural stamina) + (stamina potions you will use) + (event login calendar stamina) = total stamina. Multiply by currency-per-stamina of the best farm stage = total currency. This tells you exactly how many items you can buy. Plan your purchases before the event begins — never buy on impulse.

Refresh Strategy

Some events have a "shop refresh" at the halfway point (new items appear). Rule: Do NOT spend all your currency before the refresh. Keep 30% of your expected total in reserve. If the refresh adds new SSR shards or protocores, you want to be able to buy them. If the refresh is only materials, spend the reserve on the first half items you skipped. Example: If you expect 10,000 total currency over the event, spend only 7,000 in the first half. Keep 3,000 for the refresh.

Summary: SSR R1 > Guaranteed Protocore > Pull Tickets > Stamina Pots > Cores > SR > Everything else. Skip regular-priced materials. Calculate your total stamina before the event. Keep 30% reserve for mid-event shop refresh. Never impulse buy.
