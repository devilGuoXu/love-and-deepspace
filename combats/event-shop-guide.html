Event Shop Exchange Guide

The event shop is where your farmed currency goes to die — or to multiply your account value. Spend poorly and you lose days of stamina. Spend well and you skip weeks of farming.

ENTRY_#EVT_062026.07.02SHOP

Core Rule: Event shop currency is a limited resource. You cannot buy everything. Prioritize items that are: (1) Exclusive (cannot be obtained elsewhere). (2) Stamina-efficient (cost less stamina to farm via event than via normal stages). (3) Permanent upgrades (memories, protocores). Never spend currency on items that are cheaper or equal in normal farming, even if they seem convenient.

Tier 1 — Must Buy (Always)

These items are the highest value per currency spent. If you can only afford one category, make it this one.

SSR Memory Shards
Cost: ~3,000 currency for R1
Your #1 priority. The event SSR is exclusive for ~6 months before entering the standard pool. Getting it to R1 now saves you 6 months of waiting. Nothing else comes close in value.
Guaranteed Protocore
Cost: ~1,500 currency
Event shops always sell 1 pre-rolled SSR Protocore with optimal main stat. This is the single best value in any event shop. Equivalent to 5,000+ stamina of protocore farming.
Limited Outfit / Skin
Cost: ~2,000 currency
Exclusive cosmetic. Does not affect combat but never returns for 6-12 months. Only buy if you care about cosmetics — if you do, this is your only chance.

Tier 2 — Should Buy

These items are still excellent value. Buy them after securing all Tier 1 items.

Limited Pull Tickets
~750 currency for 5 tickets
Stamina Potions
20-30% cheaper than shop
Crystal Cores
3-5 at 50% discount
Protocore Dust
Buy discounted only

Details: Limited pull tickets (Deepspace Wish) — usually 5 at discounted rates, equivalent to 750 diamonds. Always buy these. Stamina potions (Medium/Large) are 20-30% cheaper than shop stamina pots — buy the event-limited ones. SSR Memory Enhancement Materials (Crystal Cores) are expensive to farm normally (45 stamina each); event shops offer 3-5 at 50% discount. Protocore Enhancement Materials (Dust) — buy the event-discounted ones but skip the regular-priced ones.

Tier 3 — Situational

These items are optional. Buy only if you have currency left over after Tiers 1 and 2.

SITUATIONAL
SR Memory
Buy if you haven't reached R3 on the event SR. Skip if R3+ or if you don't use the character. SR memories are easier to get from other sources.
SITUATIONAL
Character Ascension Materials
Buy only if you are actively building the character. Otherwise skip — these are farmable anytime with no time pressure.
SITUATIONAL
Gold (Credits)
Only buy if you are below 100k credits and need to level a memory immediately. Credits are the most abundant resource in the game long-term — they accumulate naturally.
SITUATIONAL
Home Decoration Items
Cosmetic only. Buy if you enjoy home decoration, skip otherwise. They have no impact on combat progression.

Exchange Priority List

Here is the complete ranked priority list for every event shop. Follow this order and you will never waste event currency.

1
SSR Memory Shards (to R1)
~3,000 currency. Non-negotiable first purchase. This is exclusive and time-gated.
2
Guaranteed Protocore
~1,500 currency. 10x efficiency over domain farming. Buy it every event.
3
Limited Pull Tickets
~750 currency for 5 tickets. Always available, always worth it.
4
Discounted Stamina Pots
20-30% cheaper than standard shop. Buy the event-limited ones only.
5
Crystal Cores (discounted)
50% off the normal stamina cost. Worth it if you are actively ascending memories.
6
SSR Memory Shards (to R2)
Only if within reach and you already have Tier 1-5 items. ~8,000 total for R2.
7
SR Memory (if missing)
Buy if you don't have it at R3 yet. Otherwise skip.
8
Protocore Dust (discounted)
Only the event-discounted ones. Skip regular-priced dust.
9
Ascension Materials (if needed)
Only if you are actively building the character right now.
10
Gold (Credits)
Only if below 100k and you need to level immediately. Gold accumulates over time.
11
Home Decor
Cosmetic only. For collectors who enjoy decoration.
12
Regular-priced Materials
Skip entirely. These are not discounted and offer no stamina advantage over normal farming.

Pro Tip: Always do the math before the event starts. Calculate: (Event duration in days × natural stamina) + (stamina potions you will use) + (event login calendar stamina) = total stamina. Multiply by currency-per-stamina of the best farm stage = total currency. This tells you exactly how many items you can buy. Plan your purchases before the event begins — never buy on impulse.

Refresh Strategy

Some events have a "shop refresh" at the halfway point where new items appear. Managing your currency reserve is critical.

Rule: Do NOT spend all your currency before the refresh. Keep 30% of your expected total in reserve. If the refresh adds new SSR shards or protocores, you want to be able to buy them. If the refresh is only materials, spend the reserve on the first half items you skipped.

Example: If you expect 10,000 total currency over the event, spend only 7,000 in the first half. Keep 3,000 for the refresh.

DO & DON'T Summary

DO
  • Buy SSR R1 before anything else
  • Buy the guaranteed protocore every event
  • Buy limited pull tickets and discounted stamina pots
  • Calculate your total stamina before the event
  • Keep 30% reserve for mid-event shop refresh
  • Follow the priority list in order
DON'T
  • Don't skip the protocore even if short on currency
  • Don't buy SR memory before SSR R1
  • Don't spend all currency before the refresh
  • Don't buy regular-priced materials
  • Don't impulse buy — always plan first
  • Don't ignore the stamina-per-currency math

Summary: SSR R1 > Guaranteed Protocore > Pull Tickets > Stamina Pots > Cores > SR > Everything else. Skip regular-priced materials. Calculate your total stamina before the event. Keep 30% reserve for mid-event shop refresh. Never impulse buy.
