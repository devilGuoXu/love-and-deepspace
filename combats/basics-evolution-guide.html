BASIC PROTOCOLS — MEMORY SYSTEMS

Memory Evolution & Ascension Guide

Ranking up memories with duplicates — stat gains, awakening unlock, and long-term planning.

ENTRY_#0512026.07.01CORE_SYSTEM

Evolution ≠ Breakthrough ≠ Enhancement: Three separate memory systems. Breakthrough raises level cap (#043). Enhancement levels up substats (#089). Evolution uses duplicate memories to increase rank. This guide covers evolution only.

How Evolution Works

Each memory has a rank (R1 to R6). Obtaining the memory for the first time gives R1. Each duplicate consumed increases rank by 1. R2 requirements: 1 duplicate + gold. R3: 2 duplicates. R4: 3 duplicates. R5: 4 duplicates. R6: 6 duplicates. Total to max rank: 17 duplicates of the same memory (1 original + 16 copies).

Stat gains per rank: +5% ATK, +3% HP, +3% DEF (flat percentages). R3 and R5 unlock bonus substat rolls. R4 unlocks the awakening slot (see #043). The awakening skill is locked behind R4 — you cannot awaken a memory until it reaches R4.

Evolution Priority

Priority 1: Main DPS SSR to R3 (bonus substat roll is significant). Priority 2: Main DPS SSR to R4 (unlock awakening). Priority 3: Sub-DPS SSR to R3. Priority 4: Main DPS to R5 (second bonus substat). Do not take any memory past R5 — the cost for R6 is prohibitive (6 duplicates) for marginal gains.

Rule of thumb: Each rank is worth roughly 3-4 substat rolls. R3 is worth ~10 substat rolls for 3 duplicates (good value). R6 is worth ~20 substat rolls for 16 duplicates (terrible value). Stop at R5 for your main, R3 for everyone else.

SR Evolution Warning

Do not evolve SR memories past R2. The stat gains from SR evolution are smaller (flat stats instead of percentage). The awakening skills on SRs are significantly weaker than SSR ones. The gold cost of SR evolution is the same as SSR — you waste gold on lower-quality stat gains. Exception: R1 to R2 on an SR you use daily is acceptable (1 duplicate cost is trivial).

Dupes From Standard Pool

Standard banner SSR duplicates should prioritize: Main DPS R4 (awakening unlock) > Sub-DPS R3 > any SSR R1 (collection bonus). If you have a choice selector ticket, pick a dupe for your main DPS over a new SSR you won't build. A new SSR at R1 with no investment is worth less than +1 rank on your built main.

Key Insight: Evolution is the most expensive system in the game per unit of gain. One extra rank costs 1-6 duplicates that could be 1-6 new memories. Only evolve memories you have geared and use in Abyss. Never evolve "just because" you have dupes — save the dupes for selector trades if available.

Summary: Main DPS to R4 (awakening), sub-DPS to R3. Never go past R5. Never evolve SRs past R2. Selector tickets > random dupes. Evolution is expensive — invest wisely.
