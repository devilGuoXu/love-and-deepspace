Awakening Material Farming

Heartbreaker, memory crystals, and ascension items — where to farm them, how many you need, and the most efficient routes.

ENTRY_#0782026.07.02MATERIALS

How to Read This: Reference format — look up the material you need and see where to farm it. The efficiency math section helps you decide whether to farm materials or use the battle pass shop.

Heartbreaker Farming

Heartbreaker is the primary awakening material. Every memory awakening costs heartbreaker + memory shards. Where to farm: Weekly bosses (3 runs per week, each gives 2-4 heartbreaker depending on boss level). Bounty Hunt: Heartbreaker Domain (open daily, 20 stamina per run, drops 1-2 heartbreaker). Efficiency: Weekly bosses are the best source — 3 runs for 6-12 heartbreaker. The domain is a supplement, not a primary source. When to farm: Only farm the heartbreaker domain if you need exactly 1-3 more heartbreaker for an awakening you want this week. Otherwise, get your weekly boss drops and stop. The domain has poor stamina-to-heartbreaker ratio compared to other uses. Total needed: Awakening one SSR memory to R1 costs 10 heartbreaker. R2 costs another 20. R3 costs another 30. Total for R3: 60 heartbreaker. At 6-12 per week, this takes 5-10 weeks of weekly boss farming. Plan accordingly.

Memory Crystals

Memory crystals are used to ascend memories past level 50. Where to farm: Bounty Hunt: Crystal Domain (alternates daily between blue, purple, and gold crystals). Energy of Memory events (limited time, good value). The battle pass shop (expensive but reliable). Efficiency: The daily domain is stamina-efficient if you need a specific crystal color. The battle pass shop should only be used if you are short on time — the diamond cost is higher than running the domain. How many: Ascending one SSR from 50 to 60 costs 30 crystals. 60 to 70 costs 60 crystals. 70 to 80 costs 100 crystals. Total for one SSR to max level: 190 crystals. For a full team of 3 operatives × 6 memories each: 3,420 crystals. This is a multi-month project.

Ascension Material Farming Route

Beyond heartbreaker and crystals, you need ascension-specific materials for each memory. Memory level-up materials (books/tomes): Best farmed from Bounty Hunt: Wisdom Domain. The higher difficulty you can clear, the better the book-to-stamina ratio. Memory ascension flowers: Specific to each element/operative. Farmed from Bounty Hunt: Ascension Domain. The rotation changes daily — check which element is available. Protocore level-up materials: Not farmed from Bounty Hunt. These come from Simulation Chamber (protocore domains). Do not confuse the two — protocore materials and memory materials are separate tracks. Optimal weekly route: Monday: Weekly bosses (heartbreaker + gold). Tuesday-Thursday: Crystal Domain (focus on the color you need most). Friday-Sunday: Wisdom Domain (books) + Ascension Domain (flowers). This route balances all material types over the week.

Stamina Efficiency Math: 1 heartbreaker domain run = 20 stamina = 1.5 heartbreaker on average. 1 weekly boss run = 60 stamina = 3 heartbreaker + 60 gold + protocore drops. Weekly boss is 6x more efficient. Rule: Always do weekly bosses for heartbreaker. Only use the domain if you have leftover stamina and need a specific small amount. For crystals, the daily domain is efficient but capped by drops. For books, higher difficulty = better value. Never farm books on lower difficulties — the efficiency gap between difficulty tiers is significant (approximately 25% more books per stamina at the highest tier).

Battle Pass Shop vs Farming

The battle pass shop offers material boxes that let you choose your reward. Good value: Heartbreaker boxes (if you need to accelerate awakening). Special crystal boxes (if you need specific rare colors). Bad value: Generic book boxes (domain farming is more efficient). Gold boxes (gold comes from many sources naturally). Verdict: The battle pass shop is a convenience tool, not a primary farming source. Use it to fill gaps in your material inventory, not as your main material source. Saving battle pass currency for limited memories or outfits is usually better than spending it on materials.

Summary: Weekly bosses are the best heartbreaker source. Crystal domains are efficient but capped by daily attempts. Battle pass shop = convenience, not primary source. Total materials for one maxed SSR: 60 heartbreaker + 190 crystals + books + flowers. This takes 5-10 weeks per SSR. Plan material farming around which memory you want to awaken next.
