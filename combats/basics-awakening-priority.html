BASIC PROTOCOLS — AWAKENING

Memory Awakening Priority

Awakening (Rank) is the most expensive upgrade in the game. Each rank requires a memory duplicate (SSR) or shards (SR). Spend your duplicates wrong and you waste weeks of progress.

ENTRY_#0662026.07.02AWAKENING

Core Truth: R1 (first awakening) is worth 2-3x more than R2 (second awakening) for most memories. R1 unlocks the memory's unique passive ability. R2 only increases stats. Never aim for R2 on a memory unless the R1 passive is exceptionally strong and you have spare duplicates.

R1 Value by Memory

S-Tier R1 (Must Awaken): Light Seeker (Xavier) — R1 adds 15% Light DMG on crit. This is Xavier's biggest damage spike. Dark Champion (Sylus) — R1 reduces execute cooldown by 3s. This enables execute every rotation. Frostguard (Zayne) — R1 extends shield duration by 2s. This closes the shield gap. A-Tier R1 (Worthwhile): Inferno Blaze (Rafayel) — R1 adds 10% burn damage. Good but not transformative. Memory of Youth (Xavier SR) — R1 adds energy regeneration. Useful for F2P. B-Tier R1 (Skip): Most SR memories. SR passives are weaker than SSR passives. Only awaken SRs if you have spare shards and use the character frequently. Rule: Awaken SSR memories before SR memories. Awaken your main DPS's memory before your support's. R1 on main DPS > R1 on support > R2 on anything.

Duplicate Usage

When you pull a duplicate SSR memory, you have two choices: (1) Use it for awakening (R1/R2). (2) Convert it to 90k XP (3 Large Crystals). When to awaken: The memory is your main operative's BiS. The R1 passive is strong (S or A tier). You do not have the memory at R1 yet. When to convert: The memory is a character you do not use. The memory is already at R1 and R2 is low value. You desperately need XP to level a different memory. Never do: Convert an SSR duplicate before reaching R1 on your main operative. R1 is worth more than any amount of XP crystals. Special case: If you pull a third duplicate (R2+), evaluate: does R2 unlock a significant power spike? If yes, awaken. If no, convert to XP.

SR Awakening Strategy

SR memories are easier to awaken because they use shards (farmable from stages). Priority: Awaken SR memories that: (1) Are your only option for a specific element. (2) Have useful set bonuses (2pc CRIT Rate, 2pc ATK%). (3) Are used in your current team. Target ranks: R3 on your main SR memories (achievable in ~2 weeks of shard farming). R1 on backup SR memories. Never go above R3 on SR memories — the stat gain is negligible and the shard cost is better spent on other SRs. F2P note: SR memories at R3 outperform SSR memories at R0 in the same slot. Do not neglect your SRs just because they are lower rarity. A R3 SR with correct set bonus is better than a R0 SSR with wrong set.

Pro Tip: The "Awakening Order" optimizer: (1) Main DPS SSR → R1. (2) Sub-DPS SSR → R1 (if used in current content). (3) Support SSR → R1 (if you need the survivability). (4) Main DPS SSR → R2. (5) Everyone else → R1. (6) SRs → R3 as needed. Follow this order and you will never waste a duplicate. If you deviate, you should have a specific reason (e.g., "Zayne R1 is more valuable for my co-op team than Xavier R2").

Material Efficiency

Awakening requires: 1 duplicate for SSR R1, 2 more for R2 (total 3), 5 more for R3 (total 8). For SRs: 30 shards for R1, 60 more for R2 (total 90), 100 more for R3 (total 190). Stamina cost per SR shard: ~15 stamina per shard from farming stages. R3 SR = 190 shards × 15 stamina = 2,850 stamina = ~12 days of natural regen. Is it worth it? For a main SR that you use in Abyss: yes. For a niche SR you use once a month: no. Be selective — you cannot R3 every SR without running out of stamina for other content.

Summary: R1 > R2 for all memories. SSR R1 on main DPS is #1 priority. SR R3 on frequently used memories. Convert SSR duplicates only after reaching R1. Awakening order: DPS SSR R1 → Sub-DPS SSR R1 → Support SSR R1 → DPS SSR R2 → SRs R3. R3 SR beats R0 SSR with wrong set. Stamina cost for SR R3 = 12 days — be selective.
