套装叠加原理：Memory与Protocore的交互

How Memory set bonuses and Protocore set bonuses interact — which stats stack additively, which multiply between systems, and how to avoid the ATK% double-stacking trap.

2026.07.11 ENTRY_#138 SET_STACKING
Written by Kaelen — Deepspace Hunter Station Team

One Sentence: Memory set bonuses (e.g., Light Seeker ATK+18%) and Protocore set bonuses (e.g., Solar ATK+12%) stack additively within each stat type, but multiply between different stat types — understanding this distinction is the difference between a good build and a wasted one.

两套独立系统

Love and Deepspace has two completely independent set bonus systems: Memory Sets (equipped on memories — Light Seeker, Dark Champion, Frostguard, Inferno Blaze, etc.) and Protocore Sets (equipped on protocores — Solar, Permafrost, Shadow, Tidal). Each system provides its own stat bonuses when you complete 2-piece or 4-piece requirements. Many players optimise each system in isolation, but the true power comes from understanding how they interact across systems.

Memory set bonuses are fixed per memory and cannot be changed. Protocore set bonuses depend on which protocores you equip. The key insight: a Memory giving ATK+18% and a Protocore set giving ATK+12% do not give 1.18 × 1.12 = 32.2% more damage. They give 1.30 × (other multipliers). The additive stacking within the same stat type means the effective gain is lower than a naive multiplication would suggest.

The two systems also differ in how their 4-piece bonuses work. Memory 4-piece bonuses tend to be unique mechanics (e.g., Light Seeker triggers a follow-up attack), while Protocore 4-piece bonuses are raw stat increases (e.g., Solar 4-piece: ATK+25% and skill damage +10%). This difference matters when deciding whether to complete a 4-piece or mix sets.

Analogy: Think of Memory sets as talents (unique effects) and Protocore sets as stat sticks (raw numbers). You need both, but you evaluate them differently. A powerful Memory set effect can justify weaker Protocore synergy — but only if you understand how the stats overlap.

加法叠加 vs 乘法叠加

The single most important concept in set stacking: same stat type stacks additively; different stat types stack multiplicatively. Here is the breakdown for every common stat:

Stat Type Stacking Rule Example
ATK% Additive within & across systems Memory ATK+18% + Protocore ATK+12% = +30%
CRIT Rate % Additive across all sources Memory 8% + Protocore 12% + base 5% = 25%
CRIT DMG % Additive across all sources Memory 15% + Protocore 25% + base 50% = 90%
Elemental DMG% Additive within same element Memory Frost+12% + Protocore Permafrost+15% = +27%
Skill DMG% Additive within type Solar 4-piece +10% Skill DMG + any other Skill DMG% sources
ATK% × CRIT DMG Multiplicative between types 1.30 ATK multiplier × 1.90 CRIT multiplier = 2.47x

The critical row is the last one: ATK% and CRIT DMG multiply each other. This is why a mix of ATK% and CRIT stats almost always outperforms stacking only ATK% — even if the individual numbers look smaller, the multiplicative interaction yields higher total damage.

数学公式 (Simplified): Total Damage ≈ Base_ATK × (1 + ATK%) × (1 + CRIT_Rate × CRIT_DMG) × (1 + Elemental_DMG%) × Skill_Multiplier. Every stat type is its own multiplicative bucket. Set bonuses that fill different buckets are worth more than set bonuses that pile into the same bucket.

ATK%双重叠加陷阱

This is the most common mistake in the game. A player equips Solar Flare memory set (ATK+18%) + Solar protocore set (ATK+12%) and thinks they have 1.18 × 1.12 = 1.3216x damage. In reality, they have 1.30x damage — because both bonuses add into the same ATK% bucket.

Assumed (multiplicative): 1.18 × 1.12 = 1.3216x (32.16% gain)
Actual (additive): 1 + (0.18 + 0.12) = 1.30x (30.00% gain)
Lost value: 2.16% effective damage — small per pair, but multiplies across 3+ ATK% sources

Now consider a realistic endgame scenario. You have:

  • Memory set bonus: ATK+18% (Solar Flare 4-piece)
  • Protocore set bonus: ATK+12% (Solar 2-piece)
  • Protocore substats: ATK+8% (spread across 3 substat rolls)
  • Memory substats: ATK+6% (spread across resonance/substat boards)
  • Base ATK from levels/ascension: effectively 100%

Total ATK% = 18 + 12 + 8 + 6 = 44% bonus. If these were multiplicative: 1.18 × 1.12 × 1.08 × 1.06 = 1.515x (51.5% gain). Actual: 1.44x (44% gain). You lost 7.5% relative damage — and that is just from ATK% alone. The same trap repeats with CRIT stats if you only stack one bucket.

The Fix: When your Memory set already gives ATK%, consider a Protocore set that gives Elemental DMG% or CRIT DMG instead of more ATK%. The set bonuses will fill different multiplicative buckets and give you more total damage. Rule of thumb: if two set bonuses target the same stat, one of them is being partially wasted.

CRIT率叠加与上限

CRIT Rate has a hard cap of 100%. Any CRIT Rate beyond 100% provides zero benefit. This makes CRIT Rate the most important stat to not over-stack — yet many players waste substats and set bonuses by exceeding the cap.

CRIT Rate sources across both systems:

  • Base: 5% (all operatives)
  • Memory set bonus: Up to 8-12% (varies by set)
  • Protocore set bonus: None directly — but Solar 4-piece gives skill damage, indirectly benefiting from CRIT
  • Protocore main stat (Slot 3): Up to 33% at +15
  • Protocore substats: Up to ~4.2% per roll, up to 5 rolls = ~21%
  • Memory bond bonuses: Typically 2-5%
  • Resonance chains: Varies by operative

Assume a typical endgame build: 5% base + 33% Slot 3 main stat + 8% memory set + 12% from substats (3 rolls at ~4% each) + 3% from bonds = 61% CRIT Rate. This is already comfortable. Adding more CRIT from a second set bonus or additional protocore substats risks hitting the 100% cap — especially when Resonance or Abyss buffs grant extra CRIT.

Optimal CRIT Rate range: 60-80% in base stats (allows room for buffs)
Warning zone: 85%+ without buffs — you will overcap with any team buff
Wasted stat penalty: Every 1% over cap = a dead substat roll that could have been ATK% or CDMG

CRIT DMG has no hard cap. Unlike CRIT Rate, CRIT DMG can scale indefinitely. Once your CRIT Rate is in the 60-80% range, every subsequent upgrade should go into CRIT DMG or ATK% — never more CRIT Rate unless your specific build has unusually low base CRIT (e.g., no Slot 3 CRIT main stat).

决策框架

When building a set combination, follow this decision flow. It will save you from the most common optimisation mistakes.

1 Identify your operative's primary damage stat (ATK%, HP%, Elemental DMG%)
→
2 Check what your Memory set already provides (ATK%, CRIT, ER, unique effect)
→
3 Choose a Protocore set that fills a different stat bucket
→
4 Evaluate: does the 4-piece bonus give >15% unconditional damage boost?

Rule of Thumb: If a 4-piece set bonus gives more than 15% unconditional damage boost, complete the 4-piece. Otherwise, mix 2+2 sets for better stat diversity. This applies to both Memory and Protocore systems independently. For example, Solar 4-piece (ATK+25% + Skill DMG+10%) easily clears this threshold. Permafrost 2-piece (Frost DMG+15%) — the 2-piece alone is already at the threshold, so the 4-piece bonus (freeze duration + frozen damage) is evaluated on its utility, not raw damage.

Examples of applying the framework:

  • Xavier + Light Seeker: Light Seeker 4-piece gives ATK+18% and a follow-up attack. The follow-up is a unique mechanic that cannot be replaced by stats. Complete the 4-piece. For protocores, Solar 4-piece gives ATK+25% + Skill DMG+10% — solid threshold, complete it. But if you lack Solar pieces, 2 Solar + 2 Shadow also works because CRIT DMG multiplies with ATK.
  • Sylus + Dark Champion: Dark Champion 4-piece gives execute damage. This is Sylus's core mechanic. Always complete. For protocores, Shadow 4-piece gives conditional +25% DMG below 50% HP — also exceeds 15% threshold. But the condition (below 50% HP) means the effective uptime is ~40-50% of a fight. If you value consistency, 2 Solar + 2 Shadow may be better.
  • Zayne + Icebreaker: Icebreaker 4-piece boosts resonance damage — core to Zayne's rotation. Complete. Permafrost 4-piece extends freeze duration — utility, not pure damage. If the content does not need extended freeze (e.g., boss immune to CC), 2 Permafrost + 2 Solar may outperform.

Quick Check: Open your current build. List each set bonus and its stat. Mark any two bonuses that target the same stat (e.g., both are ATK%). If you find a pair, ask: can I replace one with a set that gives a different stat? If yes, you likely have a free damage upgrade waiting in your inventory.

The Bottom Line: Memory and Protocore set bonuses are two independent systems that share the same additive stacking rules when they target the same stat. Always check what your Memory set gives before choosing your Protocore set. Fill different multiplicative buckets for maximum damage. Avoid stacking more than two ATK% bonuses. Keep CRIT Rate between 60-80% before buffs. And remember the 15% rule: if the 4-piece bonus unconditionally boosts damage by more than 15%, take it — otherwise mix for variety. Master these principles and you will out-damage players who have better raw gear but worse set synergy.
