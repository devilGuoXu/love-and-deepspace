EVENT ARCHIVE — EFFICIENCY

Event Efficiency Tier List

Not all events are created equal. This tier ranks events by their reward efficiency — how much value you get per stamina and time invested.

ENTRY_#EVT_122026.07.02EFFICIENCY

Efficiency Metric: Events are ranked by "diamond equivalent per 100 stamina" — converting all rewards (pulls, materials, cosmetics) into an estimated diamond value. Cosmetic items are valued at their shop price if available, or estimated based on scarcity.

S-Tier Events (Must Farm)

These events offer the highest reward density. Prioritize your stamina here over all other content. Anniversary Events: Diamond equivalent: 800-1,200 per 100 stamina. Rewards: SSR selectors, high-value limited pulls, exclusive cosmetics, double top-up reset. These are the only events where SSR selectors are available. Always clear the entire shop. Major Seasonal Events (Summer, Winter): Diamond equivalent: 500-700 per 100 stamina. Rewards: Limited outfits (1,200-2,000 diamond value), exclusive SR memories (priceless to collectors), 10-15 limited pulls, name cards, frames. The limited outfit alone makes these events S-tier. Even if you do not want the outfit, the pulls and materials make it worth farming. Half-Year / Milestone Events: Diamond equivalent: 400-600 per 100 stamina. Rewards: SSR selector, limited pulls, large gold/material bundles. For milestone events, calculate if the SSR selector fills a gap in your roster. If it does, the event is S-tier for you. If you already have all standard SSRs, it drops to A-tier.

A-Tier Events (Worth Farming)

These events are efficient but not as impactful as S-tier events. Valentine's / Seasonal Mini-Events: Diamond equivalent: 300-400 per 100 stamina. Rewards: Exclusive SR memories, name cards, limited pulls (5-10), materials. The exclusive SR memory may become relevant if the operative gets a new set bonus that synergizes with it. Boss Challenge Events: Diamond equivalent: 250-350 per 100 stamina. Rewards: Name cards, frames, protocore boxes, limited pulls. High variability based on your skill tier. If you can clear the highest difficulty, these approach S-tier efficiency. If you can only clear the first difficulty, efficiency drops significantly. Double Drop Events: Diamond equivalent: 200-300 per 100 stamina (but value depends on your current material needs). If you need protocore dust: S-tier. If you are swimming in dust: D-tier. These events are the best use of saved stamina pots. Always save 20-30 stamina pots for double drop weekends.

B-Tier Events (Optional)

These events offer average efficiency. Farm them if you have spare stamina or want the exclusive items. Mini-Game Events: Diamond equivalent: 150-250 per 100 stamina. Rewards: Name cards, frames, small material bundles. Mini-game events are inconsistent. Some have generous reward structures, others are stingy. Check community reviews before investing stamina. Login Campaigns (Non-Major): Diamond equivalent: 100-200 per 0 stamina (free). These are always worth doing because they cost no stamina. But do not spend stamina to accelerate login rewards. Web Events: Diamond equivalent: 100-300 per 0 stamina. Always complete web events — they are free. But they do not require stamina management.

C-Tier Events (Skip If Busy)

These events have low efficiency. Skip them if you are short on stamina or time. Rerun Events (if any): Diamond equivalent: 50-100 per 100 stamina. Rewards: materials only, no exclusive items. If you already have the original event items, reruns are very low priority. Small Themed Events: Diamond equivalent: 50-150 per 100 stamina. Rewards: profile frames, name cards, small material bundles. These exist primarily as filler between major events. Only farm if you want the cosmetic items. Collaboration Events (if any): Unknown efficiency — depends on the collab. Cross-promotion events often have worse reward structures than standard events. Do not expect S-tier efficiency from collab events unless data proves otherwise.

Stamina Allocation Strategy: During any event period, follow this priority: (1) Clear all event story stages once for first-clear rewards. (2) Complete all event missions/achievements. (3) Farm event shop high-value items: SSR shards > limited pulls > exclusive cosmetics > protocore boxes > XP > gold. (4) Stop farming the event shop once only low-value items remain. (5) Return to normal domain farming (protocore dust). Rule of thumb: If an event shop item costs 100 event currency and the best farming stage gives 20 currency per 10 stamina, then each item costs 50 stamina. If the item is worth more than 50 stamina worth of equivalent normal-domain farming, buy it. If not, skip it. Most event shops offer 2-3x stamina efficiency for the first 50-70% of items, then drop below 1x for the remaining filler items. Know when to stop.

Event Planning Calendar

Plan your stamina spending around the event calendar: January — Anniversary (S-Tier): Save all stamina pots for 30 days before. Spend everything during the event. February — Valentine's (A-Tier): Moderate stamina spending. March — Spring (B-Tier): Minimal stamina. Focus on normal domains. April — Milestone (A/S-Tier): Check rewards. If SSR selector included, save stamina. May — Pre-Summer (C-Tier): Save stamina pots for June. June-August — Summer (S-Tier): Full stamina spending. September — Filler (B-Tier): Normal domains. October — Halloween (A-Tier): Moderate spending. November — Pre-Winter (C-Tier): Save stamina pots. December — Winter (S-Tier): Full stamina spending. This calendar helps you plan your stamina pot saving and spending throughout the year. Do not waste stamina pots on C-tier events when S-tier events are 1-2 months away.

Summary: S-Tier events (anniversary, major seasonal, milestone): 400-1,200 diamond equivalent per 100 stamina. A-Tier (Valentine's, boss challenge, double drops): 200-400 per 100 stamina. B-Tier (mini-game, login, web): 100-250 per 0-100 stamina. C-Tier (reruns, filler, collabs): 50-150 per 100 stamina. Prioritize stamina for S and A-tier events. Save stamina pots for S-tier events. Stop farming event shops once only low-value items remain. Follow the event calendar to plan your saving and spending. Efficient stamina management during events is one of the biggest differentiators between optimized and casual accounts.
