SSR Memory Review: Offensive Sets

Deep analysis of the top offensive SSR memory sets — which ones are worth pulling for and why.

ENTRY_#0902026.06.30CORE_SYSTEM

Review Scope: This guide evaluates SSR memories by their set bonuses and stat profiles. Not all SSRs are created equal — some set bonuses are significantly more impactful than others. Pull priority is based on current meta.

Light Seeker Set (Xavier)

2-Piece Bonus: +15% Light DMG. 4-Piece Bonus: Resonance skill deals +30% CRIT DMG for 4 seconds. Rating: S-Tier. This is Xavier's best set. The 4-piece bonus aligns perfectly with his burst playstyle. If you main Xavier, this is your top priority. The set is usable on any Light-element memory, making it flexible.

Dark Champion Set (Sylus)

2-Piece Bonus: +18% Energy Recharge. 4-Piece Bonus: Ultimate refunds 15% energy on kill. Rating: S-Tier. The energy refund mechanic is unique and powerful. This set enables Sylus's execute chain playstyle. Without it, Sylus is B-tier. With it, he's S-tier. Mandatory for Sylus mains.

Inferno Blaze Set (Rafayel)

2-Piece Bonus: +12% CRIT Rate. 4-Piece Bonus: Burn ticks have +35% CRIT chance. Rating: A-Tier. Very strong in AoE content. The burn spread mechanic is excellent for Abyss floors with add waves. Slightly weaker in single-target fights. Still Rafayel's best set.

Frostguard Protocol (Zayne)

2-Piece Bonus: +18% HP. 4-Piece Bonus: Shield absorbs 15% more damage. Rating: A-Tier. Zayne's best set for hybrid builds. The HP% bonus feeds both his damage and his shields. Less impactful if you build Zayne as pure DPS.

Key Insight: A 2-piece set bonus is worth roughly 10-12 substat rolls. A 4-piece set bonus is worth roughly 25-30 substat rolls. The 4-piece bonus is almost always worth sacrificing 2-piece flexibility for. Exception: If you have god-roll off-set pieces, 2+2 can beat a mediocre 4-set.

Summary: Light Seeker and Dark Champion are S-tier must-pulls for their respective operatives. Inferno Blaze and Frostguard are A-tier strong but not mandatory. Prioritize pulling for set bonuses over individual memory stats. A complete set with average stats > mixed set with perfect stats.
