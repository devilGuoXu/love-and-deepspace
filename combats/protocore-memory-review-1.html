SSR Memory Review: Offensive Sets

Deep analysis of the top offensive SSR memory sets — which ones are worth pulling for and why.

ENTRY_#0902026.06.30CORE_SYSTEM
Written by Kaelen — Deepspace Hunter Station Team

Review Scope: This guide evaluates SSR memories by their set bonuses and stat profiles. Not all SSRs are created equal — some set bonuses are significantly more impactful than others. Pull priority is based on current meta.

Light Seeker Set (Xavier)

2-Piece Bonus: +15% Light DMG. 4-Piece Bonus: Resonance skill deals +30% CRIT DMG for 4 seconds. Rating: S-Tier. This is Xavier's best set. The 4-piece bonus aligns perfectly with his burst playstyle. If you main Xavier, this is your top priority. The set is usable on any Light-element memory, making it flexible.

Dark Champion Set (Sylus)

2-Piece Bonus: +18% Energy Recharge. 4-Piece Bonus: Ultimate refunds 15% energy on kill. Rating: S-Tier. The energy refund mechanic is unique and powerful. This set enables Sylus's execute chain playstyle. Without it, Sylus is B-tier. With it, he's S-tier. Mandatory for Sylus mains.

Inferno Blaze Set (Rafayel)

2-Piece Bonus: +12% CRIT Rate. 4-Piece Bonus: Burn ticks have +35% CRIT chance. Rating: A-Tier. Very strong in AoE content. The burn spread mechanic is excellent for Abyss floors with add waves. Slightly weaker in single-target fights. Still Rafayel's best set.

Frostguard Protocol (Zayne)

2-Piece Bonus: +18% HP. 4-Piece Bonus: Shield absorbs 15% more damage. Rating: A-Tier. Zayne's best set for hybrid builds. The HP% bonus feeds both his damage and his shields. Less impactful if you build Zayne as pure DPS.

Set Acquisition Timing and Pull Strategy

Pulling for specific SSR sets requires understanding the banner rotation schedule. Light Seeker and Dark Champion appear on limited banners approximately every 8-12 weeks. Inferno Blaze and Frostguard are available on the standard banner year-round but at lower rates. If you are a Light Seeker main, save all limited pulls for Xavier's rate-up banner and do not spend on any other limited banner until you complete the set. A complete Light Seeker 4-piece at R0 outperforms a mixed SSR set at R2 by approximately 15% total damage output.

The standard banner pity system applies to limited banners, meaning your pity count carries over between Xavier, Sylus, and other limited banners. Use this to your advantage by pulling until approximately 62 pity on each limited banner even if you do not want the rate-up memory — this builds pity toward your next guaranteed SSR without wasting resources. If you win the 50-50 early, you get a free SSR memory. If you lose the 50-50, your next SSR on the target banner is guaranteed. This "pity banking" strategy is the most efficient pulling method for F2P and low-spending players.

Set Performance by Content Type

The ranking of SSR sets changes depending on the content you are running. In Abyss floors with heavy add waves, Inferno Blaze (Rafayel) outperforms Light Seeker (Xavier) because the burn spread mechanic clears groups faster. In single-target boss fights, Light Seeker and Dark Champion are superior. In survival-heavy content like Floor 8's DoT aura or high-difficulty N109 expeditions, Frostguard Protocol (Zayne) provides more total value than any offensive set because it keeps your team alive longer.

Average the performance of your two main sets rather than optimizing for a single type of content. A balanced account with one S-tier offensive set (Light Seeker or Dark Champion) and one A-tier hybrid set (Frostguard or Inferno Blaze) clears all content more efficiently than an account with two offensive sets and no survivability options. The Abyss requires at least two teams starting from Floor 4, meaning your second team's set quality is nearly as important as your first team's. Invest in depth as well as peak power.

SSR pull rate is 0.6% per pull with hard pity at 70. Only 35% of SSRs come before soft pity (pull 62). 65% come between pulls 62-70. Understand this curve when deciding to continue pulling near soft pity.

Key Insight: A 2-piece set bonus is worth roughly 10-12 substat rolls. A 4-piece set bonus is worth roughly 25-30 substat rolls. The 4-piece bonus is almost always worth sacrificing 2-piece flexibility for. Exception: If you have god-roll off-set pieces, 2+2 can beat a mediocre 4-set.

Summary: Light Seeker and Dark Champion are S-tier must-pulls for their respective operatives. Inferno Blaze and Frostguard are A-tier strong but not mandatory. Prioritize pulling for set bonuses over individual memory stats. A complete set with average stats > mixed set with perfect stats.
