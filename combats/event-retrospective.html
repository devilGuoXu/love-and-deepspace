EVENT ARCHIVE — RETROSPECTIVE

Past Event Retrospective

A look back at every major Love and Deepspace event since launch. Understand what was offered and how future events may compare.

ENTRY_#EVT_112026.07.02RETROSPECTIVE

Why Retrospectives Matter: Past events reveal the developers' design philosophy and reward generosity. By studying past events, you can predict the structure and value of future events.

2025 Event Lineup

Launch Event (January 2025): The game launched with a 16-day login campaign. Rewards: 1,600 diamonds, SSR selector, 50 stamina potions. Design: Simple login — no shop, no farming. Valentine's Day (February 2025): First themed event. 14-day duration. Mechanics: Story stages + boss challenge. Shop: Exclusive SR memory (Rafayel), name card, chat bubble. Spring Festival (March 2025): 14-day duration. Mechanics: Mini-games + login. Introduced the "event currency + shop" model that became standard. Shop: Spring name card, profile frame, ascension materials. 100-Day Celebration (April 2025): 7-day mini-event. Login only. Rewards: 500 diamonds, 10 standard pulls. Summer Splash (June 2025): First major seasonal event. 21-day duration. Mechanics: Story stages, farming stages, boss challenge, mini-game, photo event. Shop: Exclusive SR memory (Zayne), limited outfit (Rafayel), 10 limited pulls, name card, frame. This event set the template for all future major events. Half-Year Anniversary (August 2025): 14-day login + web event. Rewards: 1,200 diamonds, SSR selector, 20 limited pulls. Halloween (October 2025): 14-day event. Mechanics: Story + boss challenge. Shop: Exclusive name card, profile frame, 5 limited pulls. Winter Festival (December 2025): 21-day major event. Mechanics: Full event suite (story, farm, boss, mini-game). Shop: Exclusive SR memory (Xavier), limited outfit (Zayne), 15 limited pulls, name card, frame.

2026 Event Lineup (Year to Date)

1-Year Anniversary (January 2026): The biggest event to date. 21-day duration. Mechanics: Login calendar, web event, special boss rush. Shop: SSR selector (all standards), exclusive anniversary name card, 20 limited pulls, 2,000 diamonds total, top-up reset. Valentine's 2026 (February): 14-day event. Exclusive SR memory (Sylus), 300 diamonds, 10 limited pulls. Spring 2026 (March): 14-day event. Mini-game focused. Profile frame, 500 diamonds, 5 limited pulls. 500-Day (April 2026): 7-day login. 600 diamonds, 10 standard pulls, 500,000 gold. Summer 2026 (June — Ongoing): Current major event. 21-day duration. Full event suite. Exclusive SR (Xavier), limited outfit (Xavier), 10 limited pulls, 800 diamonds. Pattern Analysis: Event duration has increased (14 days -> 21 days for majors). Reward generosity has increased (300 diamonds per event -> 800+). SSR selectors have become more comprehensive (standard SSRs only -> potentially limited in future anniversaries). Event shop variety has expanded. The trend is clearly toward bigger and more generous events over time.

Event Type Effectiveness

Different event types offer different value: Login-Only Events: Best value per time invested. 2 minutes/day for 7-14 days. No stamina cost. Always complete these. Story + Farming Events: The standard event type. Requires stamina investment (300-500 stamina total to clear shop). Rewards are worth 2-3x the stamina cost compared to normal domains. Always prioritize event shop over normal farming during events. Boss Challenge Events: High skill requirement. Rewards vary by performance. Aim for the highest tier you can consistently clear. Mini-Game Events: Variable rewards. Some mini-games are easy and generous. Others are frustrating with low rewards. Check community reviews before investing significant time. Web Events: Bonus rewards for minimal effort (clicking links, sharing). Always complete these — they are free rewards.

Lessons for Future Events: Based on past patterns: (1) Anniversary events will continue to be the most generous. Save resources for January. (2) Summer events consistently offer limited outfits and SR memories. If you want free cosmetics, summer events are the best opportunity. (3) Smaller seasonal events (Valentine's, Halloween) offer good rewards for minimal time investment. Do not skip them. (4) The 500-day celebration was smaller than expected — do not over-save for arbitrary day milestones. Save for anniversary and summer events. (5) Event shops have consistently improved. Early event shops had limited items. Current shops offer SSR shards, pulls, outfits, and materials. Future shops will likely be even better. (6) Login campaigns have become more generous over time. Expect future anniversary campaigns to offer 14+ day login rewards with significant cumulative value.

Missed Event Items

Some event items have never returned: Launch SSR selector (could choose any standard SSR — never reoffered). Half-Year Anniversary SSR selector (similar — never reoffered). All exclusive name cards and profile frames from events have never returned. All limited outfits from events have never returned (though some were added to the premium shop months later for diamonds). All event-exclusive SR memories have not returned except during specific rerun events. The only items that eventually returned: Some limited outfits (added to shop for diamonds 6-12 months later). Some name cards (as part of anniversary bundles). No event-exclusive SR memories have had a second release method as of July 2026. This makes event participation important for collectors. If you see an exclusive item you want, get it during the event. Do not assume it will return.

Summary: Past events show increasing generosity and complexity. Major events are now 21 days with full story, farming, boss, mini-game, and shop systems. Login events are the best time-to-reward ratio. Anniversary and summer events are the most valuable. Event types: login (best value), story+farming (standard), boss challenge (skill-based), mini-game (variable), web (bonus). Exclusive items rarely return — collect them during events. Future events will likely continue the trend of increasing rewards. Save resources for anniversary events. Complete all event shops — they offer 2-3x domain stamina value.
