DEV NOTES — PREDICTIONS

Future Content Predictions

Based on developer patterns, community data mining, and industry trends — what you should expect in the next 6-12 months of Love and Deepspace.

ENTRY_#DEV_032026.07.02PREDICTIONS

Disclaimer: These are informed predictions, not leaks or insider information. We analyze developer patterns, job postings, and industry trends. Actual content may differ. Use this as a planning guide, not a guarantee. Never spend real money based on predictions — only spend on confirmed content.

Short-Term (Next 2-3 Patches)

New Operative (Highly Likely): The game will introduce at least 1 new operative within the next 2 patches. Pattern: new operatives are teased in the story 1-2 patches before release. If a new character appears in the main story with combat animations, expect their banner within 2 patches. Element Expansion: A new element type (beyond Light/Dark/Fire/Ice) is possible but unlikely in the short term — the devs are still balancing the existing 4. More likely: existing elements gain new interactions (e.g., Fire + Light = burn that debuffs enemy DEF). New Abyss Floors: Abyss will almost certainly expand to floor 15-18 within the next 3 patches. Floor 13+ will introduce new mechanics (rotating elemental shields, multi-wave boss fights). Preparation: Save at least 2 fully leveled teams (8 operatives at 50+) for new Abyss floors. Having only 4 operatives built will be insufficient.

Medium-Term (3-6 Months)

Protocore Substat Lock / Reroll: The devs have teased this feature in developer notes. Expected implementation: A new item (Protocore Lock) that lets you lock 1 substat before enhancing. Cost: shop currency or event rewards. Impact: This is the single biggest QoL improvement possible for endgame players. Start saving protocore dust and lock items now. Guild / Crew Expansion: The existing crew system is bare-bones. Expect guild boss content, guild-exclusive shops, and guild cooperative events within 6 months. Character Bond System Expansion: Character-specific combat bonuses unlocked through bond levels. This rewards maining a character and adds a new progression system. Preparation: Build relationships with all 4 operatives equally — if bond level unlocks combat bonuses, you will want all 4 at max bond.

Long-Term (6-12 Months)

Second Anniversary: The biggest event of the year. Expect: free SSR selector (wider pool than first anniversary), double top-up reset, new limited operative, and a new permanent game mode. Powercreep Acceleration: As the game matures, new memories and protocores will have higher stat budgets. The gap between launch memories and year-2 memories will grow. This is natural for gacha games — your launch memories will still be usable but not optimal. Collab Events (Speculative): Deepspace is popular enough for crossovers. A collab with another popular game or franchise would introduce limited collab memories. These would be the rarest items in the game — never returning if the collab license expires. Preparation: Save 20,000+ diamonds (140+ pulls) for the second anniversary. This ensures you can guarantee the anniversary limited operative even with worst-case pity. If the anniversary is 6+ months away, you have time to save 50k+ diamonds easily.

Pro Tip: The best resource for future predictions is the developer's official communication channel. Read every "Developer's Note" and "Letter from the Team" — they often hint at upcoming features. Join the beta test program if available (beta testers see content 2-4 weeks before release). Job postings are another useful signal: if the devs are hiring for a "multiplayer content designer," expect more co-op content. If they hire for "AI combat designer," expect smarter enemies.

What to Save Now

Diamonds: Minimum 10k emergency fund. Target 20k+ before anniversary. Stamina Pots: Bank all medium and large pots. Do not use them unless there is a double drop event. Protocore Dust: Save 500+ dust for the expected substat lock feature. Memory XP Crystals: Save large crystals for the next limited memory you pull. Do not waste them on memories you will replace. Event Currency: Never spend event currency on materials unless you have already bought SSR shards and guaranteed protocores. Stockpile any event-exclusive currency that carries over between events (if applicable).

Summary: Short-term: new operative + Abyss expansion. Medium-term: substat lock system + guild expansion. Long-term: 2nd anniversary + powercreep acceleration. Save 20k+ diamonds for anniversary. Save 500+ protocore dust for substat lock. Bank stamina pots. Read dev notes for hints. Join beta program if available. Predictions are not guarantees — spend wisely.
