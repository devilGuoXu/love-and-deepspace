SR Memory Database: All Operatives

SR memories are the backbone of every F2P and mid-spender account. This guide covers which SRs to invest in and which to bench.

ENTRY_#MEM_052026.07.02SR

How to Read This: SR memories are ranked by their usefulness in Senior Hunter Contest and Trial Tower. A-tier SRs can substitute for missing SSRs. B-tier SRs are filler. C-tier SRs should never be invested past level 40.

SR Memory System Overview

Each operative has 4-6 SR memories available through different sources: standard banner, event shops, battle pass, and permanent gameplay modes. SR memories cap at level 60 (compared to SSR's level 80). Their base stats are approximately 40% lower than SSRs, but they cost significantly less to ascend and level. Key fact: A maxed A-tier SR (level 60, full ascension) performs at roughly 70% of a maxed SSR of the same set. This makes SRs excellent placeholders while you build your SSR roster. You should never invest limited pulls for SRs — they will come naturally. The only SRs worth actively pursuing are those in the Crew Shop and Event Shops.

Xavier SRs

Stellar Guard (Radiance Set): CRIT% main. Resonance: AoE light damage + small party heal. Tier: A — Xavier's best SR. The heal is surprisingly useful in sustained fights. Use as Radiance 4-pc filler. Moonlit Edge (Lunar Set): ATK% main. Resonance: single-target light damage + DEF buff. Tier: B — stat stick. Use only if you need Lunar set activation. Dawn Sentinel (Lightforge Set): HP% main. Resonance: shield. Tier: C — not worth building. Xavier SR verdict: Build Stellar Guard to level 50 for Radiance set filler. Skip the rest.

Zayne SRs

Frost Guardian (Frostbite Set): ATK% main. Resonance: AoE ice damage + slow field. Tier: A — reliable ice damage with excellent crowd control. Zayne's best SR. Glacial Shard (Frostbite Set): DEF% main. Resonance: party-wide DEF buff. Tier: B — niche support. Permafrost Guard (Ancient Set): HP% main. Resonance: self-heal. Tier: C — skip. Zayne SR verdict: Build Frost Guardian to level 50. It provides solid ice damage and the slow field is valuable for controlling aggro in higher floors.

Rafayel SRs

Ember Gaze (Pyro Set): ATK% main. Resonance: AoE fire damage + burn. Tier: A — strong fire damage with DoT component. Rafayel's best SR. Flame Whisper (Pyro Set): CRIT% main. Resonance: single-target fire burst. Tier: B — decent damage. Scorching Bloom (Scorching Set): HP% main. Resonance: fire DoT + small heal. Tier: C — skip. Rafayel SR verdict: Build Ember Gaze to level 50. The burn DoT synergizes well with Pyro 4-pc set bonus. Flame Whisper is a secondary option if you need a second fire SR.

Sylus SRs

Shadow Weaver (Void Set): ATK% main. Resonance: AoE dark damage + ATK debuff on enemies. Tier: A — Sylus's best SR. The ATK debuff is rare and valuable. Night Walker (Void Set): CRIT DMG% main. Resonance: single-target dark burst. Tier: B — solid damage. Dark Shroud (Veil Set): DEF% main. Resonance: taunt + self-shield. Tier: C — skip. Sylus SR verdict: Build Shadow Weaver to level 50. The ATK debuff makes it useful even in endgame teams where Sylus is your main DPS.

SR Investment Rule: Never level an SR past 60. Never spend limited resources (tuning consumables) on SR memories. The only exception is if you are hard-stuck on a specific Trial Tower floor and the SR gives the exact set bonus you need. In that case, level to 50, not 60. The cost-to-benefit ratio drops sharply after level 50 for SRs.

SR Memory Acquisition

Standard Banner: SRs drop at ~10% rate. You will max-ascend all standard SRs eventually. Crew Shop: SR memory boxes — buy these only if you need a specific SR for set activation. Otherwise spend crew coins on SSR shards. Event Shops: Limited SR memories from events often have unique effects not available anywhere else. Always buy event SR memories — even if you don't use them immediately, they may become relevant later. Battle Pass: The paid battle pass gives an SR selector. Choose an A-tier SR you don't have max-ascended yet. Do not pick C-tier SRs.

Summary: Build exactly one SR per operative: Stellar Guard (Xavier A), Frost Guardian (Zayne A), Ember Gaze (Rafayel A), Shadow Weaver (Sylus A). Level them to 50, never 60. Never spend tuning materials on SRs. Buy event SR memories. Skip C-tier SRs entirely. A well-chosen SR roster bridges the gap until your SSR collection matures.
