Event Rotation Calendar

Deepspace follows a predictable seasonal event cadence. Knowing what's coming lets you save resources and skip banners with confidence.

ENTRY_#EVT_082026.07.02CALENDAR

Core Concept: Gacha games run on a 6-week patch cycle. Deepspace is no different. Each patch has 2 limited banners (3 weeks each), 1 story event, and 1-2 side events. After every 3 patches, there is a major seasonal or anniversary event. Memorizing this cadence removes all uncertainty from resource planning.

Patch Cycle (6 Weeks)

Week 1-3 — Patch 1st Half: New story event launches (21 days). Limited banner #1 runs alongside it. New area or dungeon may be added. Week 4-6 — Patch 2nd Half: Story event continues but all story stages are unlocked. Limited banner #2 replaces banner #1. New challenge stages or boss rush event opens. Mega-Event — Every 3 patches (18 weeks): Anniversary or major seasonal. Special login calendar. Free SSR selector. Double top-up reset. 2 simultaneous limited banners. Calendar strategy: Pull only in the first 2 weeks of a patch if you want the first banner character. If you want the second banner character, pull in week 4-5. Never pull in the final week of a patch (right before a new patch) unless you can guarantee pity — the new patch might have a character you want more.

Monthly Cadence

Week 1: New monthly login calendar resets. Battle Pass resets. Shop refresh. Reset your pull tracking for the month. Week 2: Double drop weekend (usually protocore or XP domain). Week 3: Mini-game event or boss challenge (1-week duration). Week 4: Another double drop weekend (opposite domain from week 2). End-of-month login bonuses if applicable. Tip: The monthly shop refresh sells 5 limited pulls for stardust — always buy these. The battle pass is the best value purchase in the game ($5 for ~10 pulls worth of resources). If you spend any money, buy the battle pass first.

Known Seasonal Windows

January: Anniversary (estimated). Free SSR selector + top-up reset. February: Valentine's event (14 days). Limited SR memory + photo props. April: Spring / Cherry Blossom event. June-August: Summer / Beach event (major). October: Halloween event. December: Christmas / New Year event (major). Limited SSR memory. Unknown/Variable: Collab events (if any). Special anniversary livestream rewards. Developer appreciation events. Rule: Always assume a major event is 1 month away. Save 10,000+ diamonds (70+ pulls) as an emergency fund. If no major event comes, you can spend it. If one comes, you are ready.

Pro Tip: Patch notes are usually released 2-3 days before the patch. Read them carefully for: (1) New banner announcement (which character is rate-up). (2) Event duration (overlaps to track). (3) Balance changes (your current protocore builds may change). (4) New mechanics (study them before the patch drops). Join the official Discord or subreddit for patch note discussions — the community often catches details the notes miss.

Stamina Planning by Season

Pre-Anniversary (Dec-Jan): Save all stamina pots. Double drops are coming. Do not level new characters. Pre-Summer (May-Jun): Same as anniversary prep. Normal patches: Spend stamina normally but stop leveling niche characters 2 weeks before a major patch. During major events: 100% stamina into the event shop. Normal domains can wait. Between events: 100% stamina into protocore dust. Always protocore dust when there is no pressing need for event currency.

Summary: 6-week patch cycle. 2 banners per patch. Major event every 18 weeks. Never pull in the final week of a patch. Battle Pass is best value. Keep 10k diamond emergency fund. Read patch notes 2-3 days before. Plan stamina by season — event currency > protocore dust > XP > gold.
