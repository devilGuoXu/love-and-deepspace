Event Rotation Calendar

Deepspace follows a predictable seasonal event cadence. Knowing what's coming lets you save resources and skip banners with confidence.

ENTRY_#EVT_082026.07.02CALENDAR

Core Concept: Gacha games run on a 6-week patch cycle. Deepspace is no different. Each patch has 2 limited banners (3 weeks each), 1 story event, and 1-2 side events. After every 3 patches, there is a major seasonal or anniversary event. Memorizing this cadence removes all uncertainty from resource planning.

Patch Cycle (6 Weeks)

Every patch follows a predictable rhythm. Understanding this lets you time your spending perfectly.

1
Patch 1st Half (Weeks 1-3)
New story event launches (21 days). Limited banner #1 runs alongside it. New area or dungeon may be added. This is the busiest period of the patch — plan your stamina accordingly.
2
Patch 2nd Half (Weeks 4-6)
Story event continues but all story stages are unlocked. Limited banner #2 replaces banner #1. New challenge stages or boss rush event opens. The second half is typically more combat-focused.
3
Mega-Event (Every 18 Weeks)
Anniversary or major seasonal. Special login calendar. Free SSR selector. Double top-up reset. 2 simultaneous limited banners. This is the peak of the game's event calendar.

⚠ Pull strategy: Pull only in the first 2 weeks of a patch if you want the first banner character. If you want the second banner character, pull in week 4-5. Never pull in the final week of a patch (right before a new patch) unless you can guarantee pity — the new patch might have a character you want more.

Monthly Cadence

Within each patch, there is a reliable monthly mini-cadence of events and resets.

WEEK 1
Monthly Reset Wave
New monthly login calendar resets. Battle Pass resets. Shop refresh. Reset your pull tracking for the month. Buy the 5 limited pulls from the shop for stardust — always.
WEEK 2
Double Drop Weekend
Usually protocore or XP domain. Bank stamina pots the week before. This is your biggest farming opportunity of the month.
WEEK 3
Side Event
Mini-game event or boss challenge (1-week duration). These are shorter events that fit between the main content beats.
WEEK 4
Second Double Drop
Opposite domain from week 2. End-of-month login bonuses if applicable. Prepare for the next patch cycle.

Tip: The monthly shop refresh sells 5 limited pulls for stardust — always buy these. The battle pass is the best value purchase in the game ($5 for ~10 pulls worth of resources). If you spend any money, buy the battle pass first before anything else.

Rule: Always assume a major event is 1 month away. Save 10,000+ diamonds (70+ pulls) as an emergency fund. If no major event comes, you can spend it. If one comes, you are ready.

Pro Tip: Patch notes are usually released 2-3 days before the patch. Read them carefully for: (1) New banner announcement (which character is rate-up). (2) Event duration (overlaps to track). (3) Balance changes (your current protocore builds may change). (4) New mechanics (study them before the patch drops). Join the official Discord or subreddit for patch note discussions — the community often catches details the notes miss.

Stamina Planning by Season

Your stamina strategy should shift depending on where you are in the patch cycle.

Pre-Anniversary (Dec-Jan)
Save all stamina pots. Double drops are coming. Do not level new characters. Conserve every resource for the anniversary event shop.
Pre-Summer (May-Jun)
Same as anniversary prep. Bank stamina pots, stop building niche characters, and prepare for the summer event shop which typically has high-value items.
Normal Patches
Spend stamina normally but stop leveling niche characters 2 weeks before a major patch. Use this time to build your core team's protocores.
During Major Events
100% stamina into the event shop. Normal domains can wait. Event shop items are time-limited and usually offer better value than regular farming.
Between Events
100% stamina into protocore dust. Always protocore dust when there is no pressing need for event currency. This is the default state — dust farming is never wasted.

DO & DON'T Summary

✅ DO
  • Memorize the 6-week patch cycle
  • Never pull in the final week of a patch
  • Buy the battle pass — best value purchase
  • Keep 10k diamond emergency fund at all times
  • Read patch notes 2-3 days before each patch
  • Adjust stamina strategy by season
❌ DON'T
  • Don't spend all diamonds before a major seasonal
  • Don't pull on banners in the last week of a patch
  • Don't ignore the monthly shop refresh (5 pulls for stardust)
  • Don't skip patch notes — they contain critical info
  • Don't farm gold between events — farm dust instead
  • Don't treat minor events the same as major ones

Summary: 6-week patch cycle. 2 banners per patch. Major event every 18 weeks. Never pull in the final week of a patch. Battle Pass is best value. Keep 10k diamond emergency fund. Read patch notes 2-3 days before. Plan stamina by season — event currency > protocore dust > XP > gold.
