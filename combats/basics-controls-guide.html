Mobile & PC Controls Guide

Input optimization for every platform — reduce latency, improve consistency, and play comfortably.

ENTRY_#0552026.07.01OPTIMIZATION

Controls ≠ Graphics: Guide #026 covers graphics and audio settings for performance. This guide focuses specifically on INPUT — button layout, keybinds, touch sensitivity, and device-specific tweaks. Good controls make more difference than good graphics.

Written by Kaelen — Deepspace Hunter Station Team

Mobile — Touch Layout

Default mobile layout places the dodge button in the bottom-right corner with the attack button on the bottom-left. This is fine for casual play but suboptimal for advanced combat. Recommended custom layout: Swap dodge and skill button positions — dodge should be where your thumb naturally rests (right side, lower position). Move the swap button to the top-center edge so you can tap it with your index finger while your thumb handles movement and attacks.

Button size: Increase dodge and skill buttons to 120% size. Decrease non-combat buttons (menu, map) to 80% size. Opacity: Set combat buttons to 80% opacity (visible but not obscuring the field). Non-combat buttons to 30% opacity.

PC — Keybind Optimization

Default PC keybinds are functional but not optimal for speed. Recommended binds: Movement WASD (default). Attack: Left Mouse Button (default). Resonance Skill: Q (closer than default E). Swap Operative: Mouse Wheel Up/Down (faster than 1/2/3 keys). Ardent Oath: R (closer than default T). Dodge: Space (default) + Right Mouse Button (alternative). Ultimate: E (moved from default).

Mouse settings: Turn off mouse acceleration in Windows (enhance pointer precision). Set sensitivity to a consistent DPI (800-1200 DPI recommended). Lower sensitivity = more precise camera control for positioning. Higher sensitivity = faster reactions for dodging.

Input Lag Reduction

Mobile: Enable "Game Mode" on your device (reduces background process interference). Set graphics to 60fps mode (30fps adds ~33ms input lag). Disable battery optimization for the game app. Bluetooth controllers add 10-20ms lag — wired is better for competitive content.

PC: Use a wired mouse (wireless adds 1-5ms). Disable VSync in graphics settings (adds ~16ms lag). Enable "Raw Input" if available. Cap framerate to your monitor's refresh rate (60hz/120hz/144hz). Run the game in fullscreen mode (not windowed or borderless — adds ~10ms).

Per-Operative Tips

Xavier: Bind "Hold Attack" to a dedicated key (not just holding mouse button). The hold timing is tight for Charged Strike. Sylus: Bind "Stealth" to a thumb mouse button for faster access. Zayne: Increase shield button size — you need to tap it reactively. Rafayel: Bind "Swap Target" to a convenient key for burn spread targeting.

Camera management separates experienced players from novices in combat. The manual camera control mode allows independent camera movement while attacking, enabling you to see incoming attacks from off-screen enemies. The auto-camera mode follows your target but can miss peripheral threats. Switch to manual camera control for boss fights with adds and auto-camera for single-target encounters. The camera sensitivity setting of 70% provides the best balance between quick targeting and smooth tracking for most players.

Skill queuing buffers your next ability during the current animation. Press the next ability button during the current animation rather than waiting for it to complete. This increases DPS by approximately 8% through eliminated ability gaps.

Key Insight: The single biggest control improvement is separating dodge and skill onto different fingers. On mobile, that means thumb for movement + index finger for dodge. On PC, that means left hand for movement/abilities + right hand for camera/attack. Never have one finger responsible for both moving and dodging.

Advanced Control Techniques

Beyond the basic control scheme, several advanced techniques separate average players from top performers. The snap-target mechanic allows you to instantly face the nearest enemy by tapping the targeting button twice rapidly. This is useful for quickly reorienting after a dodge roll. The camera reset button centers the camera behind your operative instantly, which helps maintain spatial awareness during fast boss fights where the camera may become disoriented. Bind both of these functions to easily reachable keys or buttons for muscle memory development.

Summary: Mobile: swap dodge position, increase combat button size. PC: Q for skill, MW for swap, R for Oath, RMB for dodge. Disable mouse accel. Fullscreen + no VSync. Wired peripherals. Separate dodge finger from movement finger.
