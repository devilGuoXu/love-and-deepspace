Memory Set Farming Route

Know exactly which simulation chamber domain to run for each protocore set — no more wasted stamina on wrong domains.

How to Read This: This is a reference guide. Bookmark it and use it when you need a specific protocore set. If you are new to protocores, read the Protocore Substats Guide first.

Simulation Chamber Stage Map

The Simulation Chamber has multiple stages, each dropping specific protocore sets and main stats. Here is the complete mapping: Stage 1 (Shattered Domain): Drops Shattered Set (dodge → ATK buff) and Memory of Light (healing focus). Main stats: HP%, ATK%, DEF%. Stage 2 (Engraved Domain): Drops Engraved Set (shield → DEF explosion) and Memory of Time (support focus). Main stats: ATK%, CRIT rate, CRIT damage. Stage 3 (Frost Domain): Drops Frostbite Set (Zayne's ice damage) and Ancient Set (general ATK). Main stats: ATK%, Ice DMG%, Energy Regen. Stage 4 (Ember Domain): Drops Ember Set (Rafayel's fire damage) and Oceanic Set (support/healing). Main stats: ATK%, Fire DMG%, HP%. Stage 5 (Radiance Domain): Drops Radiance Set (Xavier's light damage) and Lunar Set (balanced stats). Main stats: ATK%, Light DMG%, CRIT damage. Stage 6 (Dark Domain): Drops Darkstar Set (Sylus's dark damage) and Chaos Set (HP-based damage). Main stats: ATK%, Dark DMG%, HP%. Higher-difficulty stages have better drop rates for gold protocores. Always run the highest difficulty you can comfortably clear.

Which Sets to Farm First

Your farming priority depends on your main operatives: If you main Zayne: Farm Stage 3 (Frost/Ancient) until you have a full +12 Frostbite set. Then farm Stage 2 for Engraved as a secondary set. If you main Rafayel: Farm Stage 4 (Ember/Oceanic) for your main set. Oceanic pieces with good substats can serve as support gear. If you main Xavier: Farm Stage 5 (Radiance/Lunar). Lunar set pieces are universally useful across all operatives. If you main Sylus: Farm Stage 6 (Darkstar/Chaos). Chaos set HP-scaling pieces are strong but niche. General priority: Main DPS set > Universal set (Lunar/Ancient) > Support set. Do not farm all 6 stages equally — focus on your main operative's set until they are geared, then branch out.

Efficient Farming Routes

Stamina is limited. Here is how to maximize value: Daily Routine: Spend 120 stamina on your main set's domain. Keep 60 stamina for weekly bosses. Spend the remaining stamina on secondary domains or level-up materials. Weekly Reset: Monday is the best day for protocore farming because weekly boss rewards reset — do those first, then farm protocores with remaining stamina. Double Drop Events: These are the best time to farm hard-to-get sets. During double drop events, only farm the domain for your primary set. Do not split stamina across multiple sets during events. Farming tracker: Keep a note of which main stats you already have. An ATK% protocore of a set you already own is worth less than a CRIT damage piece you are missing. Prioritize slots where you have gaps.

Substat Reroll Strategy: Getting the right main stat is your first goal. Getting good substats is the second goal. Do not keep farming a set once you have all 6 slots filled with correct main stats — even if the substats are bad. The substat improvement per stamina spent has steep diminishing returns once you have +12 main stat pieces equipped. Instead, farm a second set for a different operative. Better to have 2 functional sets than 1 perfect set.

Common Farming Mistakes

Most farming inefficiency comes from avoidable mistakes: (1) Farming difficulty levels that are too high — if you cannot clear in under 90 seconds, drop down a difficulty. Clear speed > higher drop rate when time is factored in. (2) Ignoring off-set pieces — a +15 Lunar piece with perfect substats is better than a +12 set piece with bad substats, even if you lose the set bonus. (3) Farming every day without a target — decide which main stat you need before entering a domain. Rotate domain targets only when you fill a slot. (4) Spending all stamina on one set for weeks — you need variety for different operatives and team compositions.

Summary: 6 Simulation Chamber stages, each with 2 sets. Farm your main operative's set first. Run highest comfortable difficulty. Prioritize main stat > set bonus > substats. Use double-drop events on primary set only. Stop farming a set once you have correct main stats in all 6 slots. Better to have 2 functional sets than 1 perfect set.
