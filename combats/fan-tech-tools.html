Community Tools Ecosystem

The fan-tech scene for Love and Deepspace is remarkably active. Developers across the globe build and maintain tools that address every imaginable player need: wish calculators that tell you how much it really costs to guarantee a memory, interactive maps that mark every collectible and wanderer spawn, protocore optimizers that solve the stat puzzle for you, and progression planners that map your route to endgame readiness.

These tools exist because the game deliberately leaves certain information opaque. Drop rates are not published. The exact math behind damage formulas is not explained in-game. The locations of every hidden resource are left for players to discover. Fan tools fill these gaps by applying data mining, community-sourced data, and good old-fashioned math to give players answers the game itself does not provide.

The ecosystem can be divided into three tiers. Tier 1 — Web Apps: Full-stack web applications with interactive UIs, usually built with React or vanilla JavaScript. These are the most polished and feature-rich tools. Tier 2 — Spreadsheets: Google Sheets or Excel workbooks that use formulas and conditional formatting to calculate, compare, and plan. Spreadsheets are easier to create and maintain than web apps, making them the most common format for community tools. Tier 3 — Mobile & Bot Tools: Discord bots, mobile-friendly PWAs, and lightweight apps designed for quick reference on the go.

The flow between the Workshop (official site tools) and Fan Corner (community projects) is bidirectional: Workshop tools often inspire fan projects, and the best fan tools sometimes get adopted or referenced by the Workshop. This guide focuses on the Fan Corner side — tools built by players, for players, with no official affiliation.

How to Build Your Own Tool

Building a fan tool is one of the most rewarding ways to contribute to the community. You do not need to be a professional developer — many of the most popular tools were built by players who learned as they built. Here is a practical roadmap to getting started.

Choose Your Stack. The simplest path is plain HTML, CSS, and JavaScript hosted on GitHub Pages — completely free, zero server costs, and no build tooling required. If you want more interactivity, learn React (the most popular choice in the fan-tool community) or Vue. For spreadsheet-based tools, Google Apps Script can add surprising power to Sheets. The Workshop section of this site has deeper dives into specific technologies.

[H]
HTML/CSS/JS
Zero setup, instant deploy via GitHub Pages. Best for simple calculators and reference tools.
[R]
React
Component-based architecture for complex UIs. Most popular framework in the community.
[S]
Google Sheets
No coding required for basic tools. Advanced formulas and Apps Script add automation.
[B]
Discord Bot
Node.js + discord.js. Ideal for quick-lookup tools and automated notifications.

Data Collection. Your tool needs data to be useful. Sources include: official game assets (screenshots, UI data), community datamine dumps (shared on Discord and GitHub), manual data collection (run content and record results), and — if you are very careful — API observation (noting what network requests the game client makes, without intercepting or modifying traffic). Never scrape the game's servers aggressively. A polite polling interval and respect for rate limits keeps your tool ethical and stable.

Tools You Need. VS Code (free, industry-standard editor), a GitHub account (for hosting and version control), basic understanding of JavaScript (arrays, objects, functions, DOM manipulation), and patience. The first version of your tool will be ugly. That is normal. Ship it anyway, then iterate based on user feedback.

Sharing Your Tool. Post in the official Discord #tools-and-resources channel, make a Reddit post on r/LoveAndDeepspaceTools or the main subreddit, and list your tool in the Community Resources megathread. A good post includes: what the tool does, a screenshot or GIF demonstrating it, the tech stack used, and a clear invitation for feedback. Be responsive to issues — users who report bugs are helping you improve the tool.

Start small, launch fast. Do not wait until your tool is perfect. The community will tell you what needs to change, and their feedback is more valuable than your assumptions. A launched prototype beats an unlaunched masterpiece every time.

Collaborative Tech Projects

Not every project needs to be a solo effort. Some of the most impactful community tools are built collaboratively — open-source repositories where anyone can contribute code, data, translations, or documentation. Joining an existing project is the fastest way to learn and make a difference.

Community Translation Tools
Open-source projects that aggregate and localize game text for non-Chinese-speaking players. Contributions needed: translations for Korean, Japanese, English, and other languages. Basic JSON editing skills required.
Data Aggregation Spreadsheets
Massive community-maintained Google Sheets that track drop rates, event rewards, memory stats, and protocore distributions. Contributors run content, record results, and submit data through forms. No coding needed — just consistency.
Wiki Contribution
The Love and Deepspace wiki (fandom and community-run variants) is always looking for editors. Write memory summaries, update character pages, correct outdated information, and add datamine findings. Requires research skills and wiki markup knowledge (easy to learn).
Automated Build Sharing
A GitHub-based project that lets players submit their builds (memory sets, protocores, team compositions) and generates shareable build cards. Built with Node.js and GitHub Actions. Contributors needed for frontend design, backend API work, and build validation logic.

How to find and join: Browse the #open-source and #collaboration channels on the community Discord. Look for pinned messages listing active projects and their contribution guidelines. On GitHub, search for repositories tagged love-and-deepspace and check the issues tab for "good first issue" labels. Start by fixing a small bug or improving documentation — this builds familiarity with the codebase and establishes you as a reliable contributor.

Ethics & Legal Considerations

Fan tools exist in a space of tolerated creativity. Papergames (the developer of Love and Deepspace) has generally not taken action against non-commercial fan tools, but there are boundaries every developer should understand and respect.

DO
Release your tool as open-source so the community can verify it is safe and learn from your code. Keep your project non-commercial — no ads, no paywalls, no Patreon gating of tool features. Include a visible disclaimer stating you are not affiliated with Papergames. Credit the game developers for all game assets and intellectual property you use.
DON'T
Monetize game assets directly (selling in-game currency, account boosting, item trading). Claim your tool is official or endorsed by Papergames. Scrape the game's servers aggressively — respect rate limits and do not overload infrastructure. Violate the game's Terms of Service, particularly sections about reverse engineering, automation, and data mining.

Best Practice Checklist: Include a disclaimer on your tool's landing page: "This is a fan-made project. All game assets and characters are trademarks of Papergames. Not affiliated with or endorsed by the official developers." Provide a clear privacy policy if your tool collects any user data (even simple analytics). If your tool uses game images or data, credit the source. Keep your project open-source — transparency builds trust.

The fan-tool community operates on goodwill. Developers who respect these boundaries build trust with both the player community and the game company. That trust is fragile — one bad actor scraping aggressively or selling unlicensed merchandise can damage the environment for everyone. Be part of the solution, not the problem.

When in doubt, ask. If you are unsure whether a feature or monetization model crosses a line, post in the community Discord and ask for opinions. The collective experience of veteran tool developers is an invaluable resource. They have already navigated the gray areas and can save you from mistakes that could get your tool shut down.

Summary: The Love and Deepspace fan-tech ecosystem is a thriving landscape of community-built tools — wish simulators, build calculators, interactive maps, event planners, and more. Anyone can learn to build a tool using free resources (VS Code, GitHub Pages, basic JavaScript) and share it through Discord and Reddit. Collaborative open-source projects welcome contributors at all skill levels, from data entry to full-stack development. Always build ethically: open-source, non-commercial, credit the original developers, and include a disclaimer. The tools you build today will help thousands of players tomorrow.
