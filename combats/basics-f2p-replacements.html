F2P Memory Replacement Guide

Not everyone has every SSR memory. If you are missing a key SSR, here is exactly which SR memory fills the gap — and how much power you sacrifice.

ENTRY_#0682026.07.02F2P

Core Concept: An optimal F2P build uses 4-6 SSR memories (from standard banner + events) and fills the remaining slots with R3 SR memories. A full-SSR build is not necessary to clear all content. A well-constructed F2P build with 4 SSRs + 2 R3 SRs can clear Abyss floor 12. The difference is execution, not memory slots.

Xavier — F2P Build

Ideal SSR setup: 4pc Light Seeker (SSR) + 2pc ATK set (SSR). If missing Light Seeker pieces: Use 2pc Light Seeker (SSR) + 2pc any ATK% set (SSR or SR) + 2pc filler. Best SR replacement: Memory of Youth (SR, Light element, ATK% set). Farmable from shard stages. R3 at R3, it provides 85% of the DPS of a R0 Light Seeker SSR. Second SR option: Starlight Vigil (SR, ATK% 2pc). Power loss: Using 2 SR memories instead of 2 SSRs costs approximately 12-15% total DPS. Acceptable for F2P.

Zayne — F2P Build

Ideal SSR setup: 4pc Frostguard (SSR) + 2pc HP% set (SSR). If missing Frostguard pieces: 2pc Frostguard (SSR) + 2pc HP% (SR or SSR) + 2pc Energy Recharge (SR). Best SR replacement: Ice Barrier (SR, HP% set). Farmable. R3 provides 5.5k HP — 80% of the shield value of a R0 Frostguard SSR. Second SR option: Healing Grace (SR, ER set). Power loss: Using 2 SR memories instead of SSRs costs approximately 10% shield value. Zayne's shield is still strong enough for Abyss floor 10 at this level.

Rafayel — F2P Build

Ideal SSR setup: 4pc Inferno Blaze (SSR) + 2pc ATK% set (SSR). If missing Inferno Blaze pieces: 2pc Inferno Blaze (SSR) + 2pc Burn DMG (SR, if available) + 2pc ATK% (SR). Best SR replacement: Flame Dancer (SR, Fire DMG set). Farmable. R3 provides 10% less burn damage than R0 Inferno Blaze SSR. Second SR option: Scorching Sun (SR, ATK% set). Power loss: ~15% AoE DPS loss. Rafayel's burn DoT is still effective even with SR memories because burn damage scales primarily with ATK, not set bonuses.

Pro Tip: The best F2P memory is the one from the event shop. Every event gives you a free SSR memory (or enough shards for R1). Never miss an event SSR — these are your bridge to endgame. A F2P player with 6 event SSRs (acquired over 6 months) is stronger than a spender with 12 random SSRs. Focused acquisition beats scattered spending.

F2P Memory Acquisition Timeline

Month 1: Beginner SSR selector (pick Xavier Light Seeker). Beginner banner SSR (20 pulls guaranteed). 1 event SSR from the current event. Total: 3 SSRs. Month 2-3: Standard banner pity SSR. 1-2 event SSRs. Total: 5-6 SSRs. Month 4-6: Full team of 6 SSRs achievable. At this point, you have a complete set — the rest is optimization. Key insight: After 6 months, a F2P account has approximately 8-10 SSRs. This is enough to build a full team of 6 with 2-4 spares. The gap between F2P and dolphin accounts is not the number of SSRs — it is the quality of protocore rolls. Protocores are the great equalizer.

Summary: 4 SSR + 2 R3 SR = Abyss floor 12 viable. Xavier: Memory of Youth (SR). Zayne: Ice Barrier (SR). Rafayel: Flame Dancer (SR). F2P power loss is 10-15% compared to full SSR — acceptable. Event SSRs are your best bridge to endgame. After 6 months, F2P accounts have 8-10 SSRs. Protocores matter more than memory count.
