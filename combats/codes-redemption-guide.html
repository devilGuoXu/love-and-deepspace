In-Game Redemption

The primary method for redeeming codes is within the game client. Navigate: Main Menu (top-right gear icon) > Settings > Account > Redeem Code. Enter the code exactly as shown — codes are alphanumeric, case-sensitive, and typically 10-20 characters. Do not include spaces or special characters unless they are part of the code. Tap confirm and the rewards will be sent to your in-game mail within minutes.

The in-game method works for all players regardless of platform (Android, iOS, PC). The redemption interface is the same across all platforms. If you play on multiple devices, you only need to redeem once — the reward is tied to your account, not your device.

Web Redemption

An alternative redemption method is available through the official Love and Deepspace website. Visit the official site, log in with your account credentials, navigate to the Redeem Code section (typically under User Settings), enter the code, and confirm. The web method is useful if you're away from your gaming device or if the in-game redemption is experiencing technical issues.

Web redemption requires the same account you use in-game. If you play on a guest account, you'll need to bind it to an email first before web redemption works. The web interface also shows your redemption history — useful for tracking which codes you've already used and when they were redeemed.

Platform-Specific

Android and iOS players use identical in-game redemption flows — there are no platform differences. PC players using the standalone client also use the same in-game flow. The only platform-specific consideration is that some codes may have region restrictions. A code distributed for the Chinese server (CN) will not work on the Global server, and vice versa. Always verify that a code is intended for your server region before attempting redemption.

Account Limits

Each code can be redeemed once per account. There is no limit to how many different codes you can redeem on a single account. Codes cannot be traded or transferred between accounts. Some codes have level requirements (e.g., "Reach Hunter Level 10" to redeem) — these are noted in the code description if applicable. Permanent codes like HUNTERGUIDE have no level requirement and work for all accounts.

FAQ

Why does it say "Code Expired"?
The code's validity period has ended. Check the code's expiration date on our active codes page. Livestream codes typically expire within 24-48 hours, making them the most time-sensitive codes to redeem.
Why does it say "Invalid Code"?
Either the code was entered incorrectly (check case sensitivity and spelling) or the code is for a different server region (CN vs Global). If you're sure it's correct and it still doesn't work, the code may have been deactivated early by the developers.
I redeemed but didn't get rewards
Check your in-game mail. Rewards are sent via mail and may take up to 5 minutes to arrive. If nothing appears after 24 hours, contact customer support with a screenshot of the successful redemption message and your UID.

Tip: The most common redemption error is typing 0 (zero) instead of O (the letter) or vice versa. When entering codes, pay special attention to characters that could be ambiguous. If a code has the letter O and the number 0, try both variations. Also, codes never include special characters like ! @ # $ % ^ & * — if you see these in a code, you've copied it incorrectly.

Summary: Code redemption is simple but requires attention to detail. Use the in-game path: Settings > Account > Redeem Code. Codes are case-sensitive, region-locked, and expire on specific dates. Common issues are typos, expired codes, and region mismatches — all easily avoidable with careful reading. Each code can be used once per account.
