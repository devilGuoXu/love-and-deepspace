Memory Acquisition Catalog: Where to Get Every Memory

Every memory in Love and Deepspace is obtainable through one of six acquisition channels. This guide catalogues all sources, rates, and optimal farming strategies so you never waste stamina or currency chasing the wrong banner.

Key Insight: Each acquisition source serves a distinct role in your account's memory progression. Standard pool fills your collection slowly over time; limited banners target specific rate-ups; shops convert unwanted pulls into guaranteed picks; shard farming offers a stamina-for-guarantee trade; and events provide freebies. Understanding which source to leverage at each account stage is the difference between a scattered collection and a focused arsenal.

Acquisition Source Types

There are six primary channels for acquiring memories in Love and Deepspace. Each has different rates, pity mechanics, and ideal use cases. Understanding when to engage with each source prevents wasted resources and accelerates your collection completion. Below is a breakdown of every source type with its defining characteristics.

★
Standard Banner
Permanent pool with slow but steady acquisition. Pity carries over between rotations. Best for passive collection over months. SSR rate 1.6%, SR rate 8%. Hard pity at 70 pulls, soft pity begins at 60.
⏱
Limited Banner
Time-windowed banners with rate-up memories. Hard pity at 70, 50/50 system. Pity carries over between limited banners of the same type. The only source for exclusive memories during their debut run.
♥
Wishing Well Shop
Exchange currency earned from pulling duplicates. 1 dupe SSR = 200 stardust. 1 SSR exchange costs 400 stardust. Allows targeted purchase of memories from the standard pool rotation.
☆
Stardust Shop
Event currency shop. Offers limited-time memory selection boxes, standard pool memories at discount, and ascension materials. Prioritize event-limited items before they expire.
⚖
Shard Farming
Domain-based acquisition where you collect memory shards over time. 3 shards per run at recommended domain level. Daily cap of 5 runs. 100 shards to craft one SSR memory. Takes 34 days of dedicated farming.
🎉
Event Rewards
Free memory giveaways through events, login campaigns, and milestone rewards. Typically SR memories or selection boxes. Low investment, high value. Always complete event missions for these.

Standard Pool Memories

The standard banner (permanent pool) contains all non-limited SSRs and SRs. You can pull using blue wish tickets earned from dailies, events, and shop refreshes. Never spend premium gems on standard banner pulls — the pool is permanent and you will acquire these memories naturally through lost 50/50s and free tickets over time. The standard pool expands as limited memories are added after their exclusive period ends, typically 2-3 patches after their debut.

Which standard SSRs are worth the wait? Some standard pool SSRs remain highly competitive even against limited memories. Prioritize these if you see them on your 50/50 loss or in the Wishing Well shop: Stellar Contract (Xavier — universal damage amp), Frostbite Oath (Zayne — freeze extension), and Ember Waltz (Rafayel — team-wide burn synergy). Avoid spending Wishing Well currency on support SRs — they drop frequently enough from standard pulls and cheap shop refreshes.

Shop Redemption Guide

Two shops allow targeted memory acquisition: the Wishing Well (stardust from duplicate pulls) and the Stardust Shop (event currency). Each serves a different purpose and has distinct exchange priorities. Misusing either can set your collection back by weeks.

Wishing Well

Exchange Rates: 1 duplicate SSR = 200 stardust · 1 SSR memory exchange = 400 stardust · 1 SR memory exchange = 50 stardust

Priority 1 — S-Tier Memory Dupes: If a meta memory (Stellar Contract, Execute Protocol) appears in the shop and you already own it, buying the dupe for resonance is the highest value use of stardust. The power gain from R1 on an S-tier memory exceeds the value of a new A-tier memory.

Priority 2 — New Memories (Gap Fillers): If you are missing a key memory that completes a set bonus or enables a team comp, buy it. Example: you have 3/4 of Frost Weaver — buy the missing piece to activate the 4-set bonus.

Priority 3 — Resources: Only if you have all S-tier dupes and all missing key memories. Convert remaining stardust to ascension crystals or protocore dust. Never buy resources before memories.

Stardust Shop (Event)

Exchange Rates: Varies by event · Memory selection box typically costs 800 event currency · Standard SSR costs 600 event currency

Priority 1 — Event-Limited Items: Memory selection boxes and exclusive namecards/avatars that are only available during this event. These will not return. Buy them first before the event ends.

Priority 2 — Standard SSRs at Discount: Some events offer standard pool SSRs at a discount (400-500 currency vs 600 normal). These are the same memories from the standard pool but cheaper — good for filling collection gaps.

Priority 3 — Ascension Materials: After exhausting limited items and discounted memories, use leftover currency on ascension crystals and XP boxes. Avoid buying protocores from the event shop — they are overpriced compared to domain farming.

Shard Farming Guide

Shard farming is the most reliable (but slowest) acquisition method. You run domains to collect memory shards, and at 100 shards you can craft one SSR memory of your choice. This is the only guaranteed non-gacha path to a specific SSR, making it invaluable for F2P players and targeted set completion.

Recommendation: Farm at Level V or higher for the best shard-per-stamina ratio. Below Level IV, the shard yield is too low to justify the stamina cost — you are better off farming protocores and using other acquisition methods. Once you reach Level V, shard farming becomes the most efficient targeted acquisition method for specific set pieces. Dedicate 100 stamina per day (5 runs) to your target memory domain. After 34 days, you will have a full crafted SSR.

Shard farming strategy: Do not shard-farm memories that are available in the Wishing Well shop. Wishing Well exchange is faster and consumes universal currency (stardust) instead of stamina. Reserve shard farming for memories that are (a) not in any shop, (b) not in the standard pool, and (c) critical to your core operative's set completion. Shard farming is also excellent for SR memories — 40 shards to craft an SR, achievable in about 14 days — which can fill set gaps while you wait for SSR drops.

Summary: Six acquisition channels serve your memory collection: Standard Banner (permanent pool, 1.6% SSR rate, 70 pity — never spend gems here), Limited Banners (time-windowed, hard pity 70, 50/50 — save 140 pulls for guarantee), Wishing Well (stardust from dupes — prioritize S-tier memory dupes, then gap fillers), Stardust Shop (event currency — buy event-limited items first, then discounted SSRs), Shard Farming (domains, 3 shards per run, 5 runs/day, 34 days per SSR — best for targeted set pieces), and Event Rewards (free SRs and selection boxes — always complete event missions). The optimal account strategy: use limited banners for rate-up priorities, shard farming for targeted set pieces, Wishing Well for dupes and gap fillers, and let the standard pool fill naturally through free tickets and lost 50/50s. Never chase a specific standard SSR with gems — patience is rewarded in a permanent pool.
