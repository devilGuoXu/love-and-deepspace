Memory XP Leveling Efficiency

Leveling memories from 1 to 60 costs millions of XP. Spend your stamina poorly and you waste weeks. Spend it right and you save months.

ENTRY_#0632026.07.02XP_EFFICIENCY

Core Reality: Leveling one SSR memory from 1 to 60 requires approximately 1,200,000 XP. At 45 stamina per domain run (average 60k XP drop), that is 20 domain runs per memory = 900 stamina per SSR memory. A full team of 9 SSR memories = 8,100 stamina = 34 days of natural stamina regen. Leveling is the biggest stamina sink in the game.

XP Domain Analysis

Memory XP Crystal Domain (Highest Efficiency): Costs 45 stamina. Drops: Large Crystal (30k XP, 67%), Medium Crystal (15k XP, 25%), Small Crystal (5k XP, 8%). Average per run: ~24k XP base, ~60k XP with weekly bonus. Weekly bonus: First 3 runs per week give 3x XP. Always use these on the hardest difficulty. Weekend double drops: When active, run ONLY the XP domain. 60k XP per run = 1.2M XP in 10 runs = one fully leveled SSR memory in 20 minutes. Pro tip: The domain's drop rate is affected by your team's total power. Higher power = higher chance of Large Crystal drops. Bring your strongest team, not your XP-sharing team, to the XP domain.

Material Conversion

You can convert unwanted memories into XP crystals. Conversion rates: 1 R memory = 1 Small Crystal (5k XP). 1 SR memory = 1 Medium Crystal (15k XP). 1 SSR memory (duplicate) = 3 Large Crystals (90k XP). Should you convert? Convert R memories immediately — they have no use. Convert SR memories only if you have R3+ of that memory. NEVER convert SSR memories — they are needed for breakthrough. Gold cost: Conversion costs gold equal to 10% of the XP value. Converting an SSR duplicate costs 9k gold. This is negligibly cheap.

Leveling Priority

Level 1-40: Costs 150k XP. Use Small and Medium Crystals only. Do not waste Large Crystals on early levels — the cost-per-level ratio is worse at low levels. Level 40-50: Costs 350k XP. Use Medium Crystals. Save Large Crystals for 50+. Level 50-60: Costs 700k XP. Use Large Crystals only — using smaller crystals here is inefficient due to the gold cost per click. Optimal strategy: Always level in batches. Level 3 memories to 40 first (for the team power boost), then push your main DPS memory to 60, then the rest to 50. Never level 9 memories to 60 evenly — focus-firing one memory is more efficient because the power spike unlocks higher domain tiers.

Pro Tip: The "XP waste" mechanic: If you over-level a memory (feed it XP beyond the max level), the excess XP is lost. Always calculate exactly how much XP you need for your target level. Use the in-game calculator (tap the level bar to see remaining XP). Wasting 50k XP is like throwing away 2 domain runs.

Stamina Pot Usage

Should you use stamina pots on XP domains? F2P rule: Only use stamina pots on XP domains during double drop events. Using them on normal XP days is 50% less efficient. Dolphin rule: Use stamina pots on XP domains if you have a new SSR memory you need to level immediately (e.g., for time-limited Abyss). Otherwise, save pots for double drops. Whale rule: Buy the daily stamina pack (60 diamonds for 120 stamina) only if you are actively leveling a memory and have no pots left. The daily pack is the most efficient diamond-to-stamina conversion in the shop.

Summary: 1-60 SSR = 1.2M XP = 900 stamina. 3x weekly bonus priority. Double drop = best time to level. Focus-fire main DPS memory first. Convert R memories, keep SSR duplicates. Never waste XP from over-leveling. Stamina pots only during double drops.
