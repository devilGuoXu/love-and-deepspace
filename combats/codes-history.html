Release Patterns

Analysis of the code archive reveals consistent release patterns. Codes drop every 4-6 weeks on average, with clusters around major events. The most reliable code sources are: Major Version Updates (every 6-8 weeks, typically 1-2 codes), Developer Livestreams (1 code per stream, 24-48 hour validity), Social Media Milestones (every 100K followers, typically 1 code), Seasonal Holidays (Christmas, New Year, Summer, Valentine's Day — 1 code each), and Game Anniversaries (the biggest code drops of the year).

The average code value has increased over time. Early codes (2024) averaged 100-150 gems. Current codes (2026) average 200-300 gems plus additional materials. Anniversary codes are outliers at 300-500 gems plus premium rewards. This trend suggests future codes will continue to increase in value as the game matures and the playerbase grows.

Value Analysis

The total value of all redemption codes since launch is approximately 2,500+ gems, 500,000+ gold, 30+ SSR shards, and dozens of material boxes. For F2P players, code rewards represent approximately 10-15% of total free gem income. The best-value codes are consistently the anniversary rewards and social media milestone codes. Livestream codes, while smaller, are the easiest to miss because of their 24-48 hour expiry windows.

Statistics

Code release frequency averages 1 code every 18 days. The longest gap between codes was 45 days (between launch and the first social milestone). The shortest gap was 2 days (back-to-back codes during a livestream + update week). The most common reward value is 150 gems. The rarest reward type is exclusive cosmetic items (only 3 codes have included them so far). All codes combined account for roughly 4% of the total free gems a day-1 F2P player would have earned.

Tip: Historical data shows that codes almost always drop on Wednesdays or Fridays between 10:00-12:00 server time. If you want to catch codes as they release, check official channels during these windows. Livestream codes are announced during the stream itself — watching the stream live is the only way to get the full window for those codes.
