Memory Upgrade Priority

Not all memories are worth maxing. Learn which ones to ascend, which skills to level, and when to stop.

ENTRY_#0322026.06.30PRIORITY

Golden Rule: A level-60 SSR with the right stats beats a level-70 SSR with wrong stats. Never ascend a memory just because you can — ascend it because the stats are right.

What Makes a Memory Worth Upgrading

Primary Stat Match: The main stat matches your operative's scaling. ATK% for Xavier/Rafayel, Energy Recharge for Sylus, HP% for Zayne. Wrong main stat = bench the memory. Substat Quality: At least 3 of 4 substats should be useful. CRIT Rate, CRIT DMG, ATK%, ER are always good. Flat DEF/HP are always bad. Set Bonus: The 2-piece and 4-piece set bonuses should synergize with your build. Don't force a set bonus with bad stats.

Upgrade Priority Order

Tier 1 (Immediate): SSR memories with perfect main stat + 3+ good substats. Take these to level 60 first. They form your core build. Tier 2 (Next): SSR memories with good main stat but 2 good substats. Take to level 50. They fill gaps until you get Tier 1 pieces. Tier 3 (Maybe): SR memories with perfect stats. Take to level 40-50 only if they fill a Stellactrum color gap. Tier 4 (Don't): Any memory with wrong main stat. Salvage for upgrade materials.

Skill Leveling Priority

Skill leveling costs increase exponentially. Level 1-6 is cheap. Level 7-10 is expensive. Priority: Resonance Skill (primary damage) > Ardent Oath (burst) > Support Skill (utility) > Basic Attack (last). Stop at level 6 unless the memory is a core piece. Level 7+ is only for your absolute best memories.

Key Insight: A level-50 memory with perfect stats deals more damage than a level-70 memory with bad stats. The ascension materials you save by not upgrading bad memories can fully ascend one good memory. Be picky. Salvage aggressively. Quality over quantity.

Summary: Main stat > substats > set bonus. Level 60 is the sweet spot for DPS. Level 50 for supports. Level 70 only for god-roll SSRs. Skill level 6 is baseline — level 10 is for your absolute best piece. Salvage anything with wrong main stat without hesitation.
