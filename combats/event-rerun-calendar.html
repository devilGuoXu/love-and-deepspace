How Reruns Work

Rerun System: Select events return 6-12 months after their original run. Reruns have the same structure but reduced rewards (typically 50-70% of original currency). Limited SSR memories usually return with the rerun. Exclusive outfits from seasonal events typically do NOT return — they are one-time exclusives. The rerun shop replaces exclusive cosmetics with farmable resources.

The rerun system is designed to give new players a second chance at limited SSR memories while preserving the exclusivity of cosmetic items. The reduced rewards encourage original participation without making reruns too rewarding. If you participated in the original event, the rerun offers diminished returns — you already have the SSR memory and outfit, leaving only farmable resources in the shop. For new players who missed the original, reruns are a valuable catch-up mechanism.

Rerun banner mechanics: SSR memories that were featured in event banners return as rerun banners. These banners run alongside the rerun event and have the same pity system as original banners. The banner duration is typically shorter (7-10 days instead of 14). Plan your pull savings accordingly — if you want a rerun SSR memory, have 140 pulls ready before the rerun starts.

Important distinction: There are two types of "reruns." (1) Event reruns — the entire event returns with reduced rewards. (2) Banner reruns — the limited SSR memory returns on a new banner without the event. Banner reruns are more common than full event reruns. Do not confuse the two — check announcements to see whether the event itself returns or just the memory banner. Full event reruns include the minigames and story content; banner reruns are just the gacha.

Confirmed Reruns

These events have been confirmed to rerun through official announcements or reliable datamines.

SUMMER FESTIVAL RERUN
Expected: July-August 2026 — Reduced rewards — SSR memory returns
The Summer Festival was the most popular event of Year 1. The rerun is confirmed for Summer 2026 to coincide with the real-world summer season. Rewards will be reduced (approximately 60% of original currency rates). The limited SSR memory (Summer Splash) will return on a rerun banner. The exclusive summer outfits will NOT return — those remain exclusive to original participants. New players should prioritize this rerun for the SSR memory and the generous shop.
WINTER WONDERLAND RERUN
Expected: December 2026 — Full rerun with SSR memory
Winter Wonderland rerun is expected for the 2026 holiday season. The original event was praised for its atmosphere and story content. The rerun will include the full story and minigames but reduced currency rewards. The limited SSR memory (Winter Romance) returns on banner. Exclusive winter outfits from the original run will not return. The SSR memory is worth pulling for — it is a strong support memory that fits multiple team compositions.
CHERRY BLOSSOM EVENT RERUN
Expected: March-April 2027 — Seasonal rerun
The Cherry Blossom event (Spring 2026) is expected to rerun a year after its original run. The event featured a beautiful garden map, photography challenges, and a limited SSR memory. The map itself may become permanent based on community requests — but the exclusive photo mode filters from the event will remain limited. The rerun banner will feature the same SSR memory as the original.

Rerun preparation — confirmed events: For each confirmed rerun, start saving pulls 2 months in advance. You need 140 pulls to guarantee the SSR memory. Check the event preview announcements (usually 2 weeks before the rerun) to confirm the SSR memory's identity and stats. If the memory is meta-relevant, prioritize pulling. If it is niche, consider saving for the next new event instead.

Speculated Reruns

These events have a moderate to high probability of rerunning based on patterns and community discussions.

BOSS CHALLENGE — VOID CORRUPTOR
Probability: 70%. The Void Corruptor boss challenge was the first major boss event. It introduced a unique boss mechanic (void phases) that was well-received. The event's limited SSR memory (Void Walker) is a strong DPS memory that many new players missed. A rerun would give newer players access to this memory while adding a new boss variant for veterans. Expected rerun window: late 2026 or early 2027. The boss itself may become a permanent addition to the Abyss rotation.
PHOTOGRAPHY CONTEST — GOLDEN HOUR
Probability: 65%. The Golden Hour photography contest was the first community photo event. While the event itself was simple, the exclusive photo filters (warm glow, golden vignette) are highly sought after. A rerun would bring back these filters for new players. The format will likely be improved based on community feedback about the original (less time-gating, clearer requirements). Expected rerun window: uncertain — photo events may become a recurring monthly feature rather than discrete events.
CO-OP BOSS EVENT — TRIAL OF UNITY
Probability: 60%. The Trial of Unity co-op event tested team coordination with a multi-phase boss. The event was moderately popular — praised for challenge, criticized for requiring coordinated groups. A rerun would likely include a matchmaking improvement and difficulty scaling options. The limited SSR memory (Unity's Bond) is a support memory that enables interesting team compositions. Rerun window: pending co-op system updates.

Unlikely to Rerun

Some events are unlikely to rerun due to their nature or the developer's stated policies.

Anniversary eventsEach anniversary is unique. The 1st anniversary event will not rerun. Anniversary SSR memories may return on standard banner after 2+ years (speculated).
Collaboration eventsCollab events are IP-licensed and almost never rerun due to licensing costs. Any collab-exclusive outfits or memories are permanently limited.
Launch events
Launch events were simple login campaigns with basic rewards. They will not return as events. Equivalent rewards may appear in new player catch-up campaigns.
Beta/test eventsEvents that were part of beta testing or limited regional tests will not return. Any rewards from these events are exclusive to early participants.

Acceptance: If you missed a collab event or anniversary event, the exclusive items are likely gone forever. Acceptance is healthier than FOMO. The game has enough ongoing content that missing one event's exclusives does not meaningfully impact your account. Limited SSR memories are the exception — they may return on future banners even if the event does not return. Cosmetic items (outfits, nameplates, filters) are the truly permanent exclusives.

Preparation Strategy

Being prepared for reruns ensures you never miss an important SSR memory a second time.

1
Track rerun dates
Maintain a personal calendar of expected reruns based on this guide and community updates. Set reminders 2 months before expected rerun dates to start saving.
2
Maintain pull savings
Always maintain a baseline of 70 pulls (one pity) for unexpected rerun announcements. If you spend below 70, prioritize saving back to 70 before spending on new banners.
3
Research the SSR memory
When a rerun is announced, check the memory's stats and usage in the community tier list. Not all limited memories are worth 140 pulls. Some are niche or outclassed by standard memories.
4
Prioritize by need
Rerun SSR memories should be prioritized based on your roster gaps. If you lack a good support memory, prioritize support memory reruns. Do not pull for a memory just because it is limited.
5
Set a spending limit
Decide in advance how many pulls you are willing to spend on a rerun banner. Stick to your limit even if you do not get the memory. There will be another opportunity — or a better memory will release.
DO
  • Save 70 pulls minimum for unexpected reruns
  • Research memory stats before pulling
  • Prioritize memories that fill roster gaps
  • Set and respect spending limits
  • Participate in rerun events for free resources
DON'T
  • Don't FOMO pull — limited ≠ good
  • Don't skip current events to save for unconfirmed reruns
  • Don't expect exclusive cosmetics to return
  • Don't spend real money on rerun banners
  • Don't ignore rerun events — free resources are free resources

Rerun calendar management: Create a simple spreadsheet: column 1 = event name, column 2 = original date, column 3 = expected rerun window, column 4 = SSR memory name, column 5 = memory tier (pull priority). Update this sheet every patch. Review it before deciding to spend pulls on current banners — if your most-wanted rerun memory is coming in 2 months, skip current banners and save. This spreadsheet approach prevents impulse spending and ensures you always have enough pulls for the memories you want most.
